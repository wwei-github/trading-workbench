## 趋势反转打法（123 法则）

**前提**：`signal_type == "trend_reversal"`（趋势中收盘价突破关键位，即第②步已发生）。

**纪律**：第②步发生时**不立即追单**。等第③步确认：向上突破压力位后回踩不破（原压力位翻转为支撑）/ 向下跌破支撑位后回抽不破（原支撑位翻转为压力）+ 出现同向金K。当前信号若出现在回踩确认位置 → 可介入；若只是破位当根 K 线 → skip（追破位胜率低）。

**入场**：锚点 = 被回踩确认的关键位（support/resistance，即角色已翻转的原突破位）。止损锚点 = 123 转折点（本次摆动极值），用 support/resistance 锚加 offset 表达外侧 0.5×ATR。

**止盈**：目标 = 前一波幅 1:1 起步（前段趋势的高度），tp1 需锚定入场方向前方的关键位（做多看上方压力位、做空看下方支撑位），tp2 = 更远一档关键位。

**仓位**：反转结构早期失败率高，**仓位减半**（recommendation 上限 70）。

**例外**：破位伴随放量 + 大阴/大阳实体饱满 + 大盘同向共振时，可直接破位追单，但止损放宽至 123 点外侧且同样减仓。
