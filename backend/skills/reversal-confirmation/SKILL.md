## 趋势反转打法（123 法则）

**前提**：`signal_type == "trend_reversal"`（趋势中收盘价破前高/前低，即第②步已发生）。

**纪律**：第②步发生时**不立即追单**。等第③步确认：价格回踩被突破位不破（回踩支撑的前高变支撑 / 回踩压力的前低变压力）+ 出现同向金K。当前信号若出现在回踩确认位置 → 可介入；若只是破位当根 K 线 → skip（追破位胜率低）。

**入场**：锚点 = 被回踩确认的关键位（prev_high/prev_low）。止损锚点 = 123 转折点（本次摆动极值），offset 外侧 0.5×ATR。

**止盈**：目标 = 前一波幅 1:1 起步（前段趋势的高度），tp2 = 更远结构位。

**仓位**：反转结构早期失败率高，**仓位减半**（recommendation 上限 70）。

**例外**：破位伴随放量 + 大阴/大阳实体饱满 + 大盘同向共振时，可直接破位追单，但止损放宽至 123 点外侧且同样减仓。
