## 结构破位回踩打法（structure_break）

三种经典结构打法的合并归类，共同本质：**围绕前高/前低的破位与回踩做文章**。按行情阶段选子形态：

### 三种子形态（判定与入场步骤）

**① 123法则（趋势反转，斯波朗迪）**——用于 trend_reversal 信号
1. 破：下跌趋势跌破前一个明显低点（上升趋势则跌破=做空方向相反，下同镜像）
2. 调：反弹不再创新低（若反弹直接创出新高又迅速回落 → 演变为 2B 形态）
3. 破：价格再度突破反弹前高点时入场（第③步是决定性确认，三条件不必按序出现）
- 入场锚点 = 被回踩确认的关键位；止损 = 123 转折点（本次摆动极值）外侧 0.5×ATR
- 优点：反转确认较稳；缺点：等第③步确认有滞后，入场偏晚、止损空间偏大

**② N字结构（趋势延续）**——用于 uptrend / downtrend 信号
1. 上涨回调不破起涨点（前低）→ 放量突破前高（N字右侧启动）
2. 入场：突破后回踩不破前低时进（第二买点比破位点更稳）
3. 止损 = N字中间低点（破中间低点 = 结构破坏，立即失效）
- 口诀：放量突破前高买，缩量回踩不破前低加
- 优点：止损贴结构、盈亏比清晰；缺点：震荡市假突破频繁，形态破坏即失效

**③ 2B法则（假突破反手）**——用于 trend_reversal 信号
1. 价格创新高/新低后**未能持续**，迅速收回前高下方/前低上方（假突破成立）
2. 反向入场：止损设失效极值处（假突破的那根极值）外侧小缓冲
3. 盈亏比最佳（止损极小、目标看反向结构位），但胜率偏低，必须严格止损、轻仓试错
- 优点：入场位贴近极值点，风险最小化；缺点：仍可能连续假突破反复扫损

### 合并后的优缺点
- ✅ 只依赖高低点结构，客观不依赖指标；止损全部锚定结构位；能较早捕捉反转与延续
- ❌ "明显高低点"的界定偏主观；123 确认滞后；2B 胜率偏低；**震荡市表现最差**（高低点紊乱、假突破连发）

### 放弃条件（命中任一即 skip 或改判）
1. 结构归类为震荡区间（range_bound）→ 改用区间边缘反转（range_edge），本打法在震荡市失效率最高
2. 突破/回踩无量能配合（缩量假突破除外，2B 反而要缩量突破）
3. 大周期与小周期方向矛盾（多周期不共振时降级处理：recommendation ≤ 60）
4. 2B 进场后再次扫损 → 不二次进场（连续假突破=变盘前兆，等方向选择）
