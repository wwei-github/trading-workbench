## 顺势回踩打法

**前提**：趋势结构明确（uptrend=HH+HL / downtrend=LH+LL），且 EMA 形态与信号方向一致（EMA 多头排列支撑做多、空头排列支撑做空）。EMA 与信号方向矛盾时本打法降级（recommendation ≤ 60），方向以指标多数决为准（EMA 排列不构成方向限制，见系统提示词纪律）。

**入场**：上涨趋势回踩支撑位出现看涨金K → 做多，锚点 = 该支撑位（摆动低点）；下跌趋势反抽压力位出现看跌金K → 做空，锚点 = 该压力位（摆动高点）。止损锚点 = 信号结构位锚（support/resistance）加负/正 offset，放到锚点外 0.5~1×ATR。

**止盈**：tp1 = 入场方向前方的最近一档结构位（做多=上方摆动高点，做空=下方摆动低点）；tp2 = 再前一档同类结构位。复算盈亏比须达系统铁律（AI_RR_MIN，程序复算不足即打回）。盈亏比不足时**不要直接 skip**——先看事实包 4h 背景：排列中等/强且柱线同向（动能衰减仍算同向）时按系统提示词「盈亏比取舍」改选 trail，把止盈一参考价上移到趋势目标位（前高/通道上沿/1.5×ATR 延伸）复算达标即可；仅 4h 弱排列/震荡/柱线已翻向时才 skip（2026-10-10 BTWUSDT 个案：强排列下因结构位口径盈亏比 0.7 直接 skip 漏掉 trail 路径）。

**加分项**：回踩缩量（量能分位 < 30%）说明抛压轻；入场贴摆动结构位（不悬空）说明位置可靠。

**减分项**：回踩放量长阴/长阳击穿位置；EMA 刚死叉/拐头向下还做多。
