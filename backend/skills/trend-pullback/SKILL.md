## 顺势回踩打法

**前提**：4h 背景为宏观同侧态（「方向约束（硬性）」行六态＝顺势；缠绕/拐头双向禁开、过渡态自评），方向由方向票（MACD/布林带/RSI 多数决）确立。EMA 排列仅作趋势背景与动能参考（金叉/死叉/拐头是动能转换信号），**不构成方向限制**（多头排列不禁止做空、空头排列不禁止做多，见系统提示词纪律）；EMA 与信号方向矛盾时不因之下调方向判定，只在评分上适度保守。

**入场**：趋势方向回踩支撑位出现看涨金K → 做多，锚点 = 该支撑位（摆动低点）；反抽压力位出现看跌金K → 做空，锚点 = 该压力位（摆动高点）。止损锚点 = 信号结构位锚（support/resistance）外 0.3%~0.5%，与金K窗口极值兜底两锚取更远者（细则以系统提示词止损纪律为准）。

**止盈**：tp1 = 入场方向前方的最近一档结构位（做多=上方摆动高点，做空=下方摆动低点）；tp2 = 再前一档同类结构位。复算盈亏比须达系统铁律（AI_RR_MIN，程序复算不足即打回）。盈亏比不足时先调入场价，仍不达标**如实 skip**。

**加分项**：回踩缩量（量能分位 < 30%）说明抛压轻；入场贴摆动结构位（不悬空）说明位置可靠。

**减分项**：回踩放量长阴/长阳击穿位置；EMA 刚死叉/拐头向下还做多。
