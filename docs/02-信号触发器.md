# 02-信号触发器

> 现行版本：RULE_VERSION v2026-10-01（2026-10-01）。本文对照代码整理，以代码为准；历史拍板记录见 docs/archive/。

## 1. 概览

触发器体系回答的问题是：**在方向票（MACD/布林带/RSI）多数决给出的候选方向上，此刻是否出现了与方向一致的入场时机**。方向判定权不在触发器（由 `technical.compute_indicator_votes` 方向票多数决决定，衔接 01 文档），触发器只做三件事：

- **T1a 结构突破**（`trigger_breakout`）：收盘越过最近一个未被突破的摆动结构前高（做多）/前低（做空）——N 字/趋势延续的结构性破位；
- **T1b 趋势突破**（`trigger_trend_breakout`）：收盘破 N 根 Donchian 滚动高低轨——强趋势连续新高/新低、无未破结构位可越时的追势入场；
- **T3 回踩两段式确认**（`trigger_pullback_confirm`）：回踩触点企稳 + 同向金K，当根确认或**触碰根后 1..N 根已收盘K线窗口内确认**（N=`pending_confirm_window_bars`，默认 3；N=1 即旧「恰好下一根」口径）。其中当回踩触点为 **1h EMA21** 时须先通过 **1H 结构门**（`structure_1h`：三线排列 + 快中线发散史 + EMA144 方向）——2026-10-15 起由硬门**降级为软校验**：结构不过**不否决**，照常产出信号（带 `structure_gate=False` 证据、由质量分重罚 −15），其余触点（retest/swing/4h EMA21/EMA55）不受此门约束（2026-10-12 拍板硬门，2026-10-15 降级，docs/21 O9）。

三者互斥、按优先级短路：**T1 突破 > 当根确认 > 次根/N 根内确认 > 触碰转 pending**。纯金K触发（`trigger_candlestick`）已于 2026-09-29 下线——金K必须与触点配合，无触碰无有效 pending 的金K一律不触发。趋势回踩金K确认（`trigger_trend_pullback`）已于 2026-10-12 下线（它并非独立信号，而是同一回踩路径的质量分层标注，已并入 `trigger_pullback_confirm`；1H 结构门改为 ema21 触点软校验，2026-10-15 降级不否决）。

所有信号判定基于**已收盘 K 线**（`klines[-2]`），`klines[-1]` 是未收盘根、只取现价（`scanner.py:227-228`）。同根 K 线同结果，免疫扫描时刻漂移与轮次缺失。

### 1.3 总入口签名（trigger.py:351-357）

```python
detect_trigger(klines, direction, pending=None, flt=None, retest=None, htf=None)
  -> (trigger, pending_op)
```

- `direction`：1 多 / -1 空（方向票多数决 `net` 的符号）；
- `pending`：该币活跃 pending 快照 `{id, direction, stage1_candle_open, touch_ref}` 或 None（scanner 批量预取）；
- `flt`：`ScanFilters` 参数组；None 时按 settings 解析（`resolve_scan_filters(None)`），策略函数不读 DB；
- `retest`：scanner 侧活跃破轨事件快照 `{price, direction, candle_open}`（naive UTC，与 K 线时间戳同源）；
- `htf`：4h 原始K线（尾根未收盘，与 analyze_htf_background 同源序列）；用于 ema21_4h 触点探测与 T3+ 趋势门升级判定，None/过短时触点静默跳过、趋势门不升级（不阻断 1h 触点体系）；
- 返回 `(trigger, pending_op)`：trigger 为命中 dict（type/direction/position/touch_ref/pattern/breakout_pct/reason 等）或 None；pending_op 为 None 或 `{"op": "upsert"|"confirm"|"supersede"|"expire", ...}`，upsert/expire 由 scanner 结合 DB 行补全（方向反转拆两步、quality/votes 快照填充），trigger.py 保持无 DB 依赖。

## 2. T1a 结构突破（trigger_breakout）

判定代码：`trigger.py:364-405`（结构位求解 `_unbroken_pivot_level` 见 `trigger.py:273-292`）。

### 2.1 判定条件（做多，逐条）

1. **前置**：`n ≥ 30` 根 K 线，`direction ∈ {1, -1}`（`trigger.py:335`）。
2. **结构取材**：`recent_swings(klines[:-1], order=swing_order, n=10)`——摆动结构取信号K线**之前**的已收盘K线，信号K线是潜在破位者、不参与结构检测（否则其极值收盘会杀死邻近 pivot，如破位阴线压掉前低，`trigger.py:365-367`）。摆动点为收盘价口径、两侧各 `swing_order` 根确认（2026-10-12 起触发层跟随「摆动点阶数」配置，默认 3，与 AI 事实包/K线标注同源）、无前视（`__init__.py:19-51`）。
3. **突破位**：`_unbroken_pivot_level` 从最新向最旧扫描摆动高点，判定区间 = 摆动K线后一根 ~ 信号K线前一根（`klines[idx+1:-2]`），任一收盘 > 该位即前高已破，继续向更旧找；**全部已破返回 None——无结构前高可破，不触发 T1a**（此时回落 T1b）。收盘恰等于该位是触碰不是破位。
4. **顺向长实体**：`_is_solid_breakout_candle`（见 §4.3）必须通过，否则连结构位求解都不进入（`solid=False` 时 `ref` 保持 None，`trigger.py:372-379`）。
5. **最小幅度**：`close ≥ ref × (1 + breakout_threshold)`（默认 0.2%，毛边不算，`trigger.py:386`）。
6. **追高上限**：`close > ref × (1 + breakout_max_pct/100)` 时拒绝（默认 1.5%，0=关闭，`trigger.py:381-384`）——先判上限再判下限，超幅直接短路本分支。注意 T1a 被追高拦截后**会**落回 T1b 判定（代码注释明确"追高拦截"是回落条件之一，`trigger.py:406-408`）：对老结构前高是追高、对 20 根滚动轨可能幅度合规，此时按 T1b 触发。

### 2.2 返回 payload（命中时，做多）

```python
{
  "type": "trigger_breakout", "direction": 1, "position": "resistance",
  "breakout_level": ref, "candle_open": <信号K线开盘时间>,
  "pattern": None,
  "position_ref": "突破前高 {ref:.6g}",
  "breakout_pct": (close - ref) / ref * 100,
  "reason": "指标同向·[放量X.X倍·]长实体收盘突破前高({ref:.6g})",
}
```

`breakout_level` 与 `candle_open` 由 scanner 落库 `breakout_events`（破轨事件），是回测触点（retest）的事实源（scanner.py:201-210）；**触发类型白名单过滤不影响事件记录**——破轨是市场事实，与是否产生突破信号无关。

### 2.3 空头镜像（做空）

- 突破位 = 最近未破的摆动**低点**（`swings["lows"]`）；`close ≤ ref × (1 - thr)` 触发；
- `position = "support"`，`position_ref = "跌破前低 {ref:.6g}"`；
- 长实体要求阴线（`close < open`），其余门槛（幅度/追高/实体门/放量加分）完全对称（`trigger.py:396-405`）。

### 2.4 pending 处置

T1a/T1b 命中时 `_close_op(pending, direction, "breakout")`（`trigger.py:295-303`）：

- 同向活跃 pending → `{"op": "supersede", "reason": "breakout"}`（被更强触发抢先）；
- 方向反转的 pending → `{"op": "expire", "reason": "direction_flip"}`——死因是票崩而非被抢先，审计语义优先。

## 3. T1b 趋势突破（trigger_trend_breakout）

判定代码：`trigger.py:406-440`。

### 3.1 Donchian 轨

- 窗口 `klines[-2 - chan_n : -2]`：`chan_n = flt.breakout_channel_bars`（默认 20，最小 5），**不含信号K线自身与未收盘根**，防"自己破自己"；要求 `n ≥ chan_n + 2`；
- `chan_high = max(high)`、`chan_low = min(low)`（滚动轨极值）；
- 做多：`close ≥ chan_high × (1 + thr)` 且未超追高上限（按轨价衡量）→ 触发，`position_ref = "突破{chan_n}根轨高 {chan_high:.6g}"`，reason = `指标同向·[放量·]长实体收盘突破{chan_n}根Donchian上轨({chan_high:.6g})`；
- 做空：`close ≤ chan_low × (1 - thr)` 对称，`position_ref = "跌破{chan_n}根轨低 {chan_low:.6g}"`，`position = "support"`。

### 3.2 与 T1a 的互斥回退关系

同一根信号K线按突破位口径互斥归类，**结构优先**（`trigger.py:352-363` 注释与代码顺序）：

1. 先判 T1a：存在未破结构位且收盘越位 → 返回 T1a，本轮结束；
2. T1a 未命中（无未破结构位 / 幅度不达 / 追高拦截）→ 落到 T1b 判 Donchian 轨。

语义分工：T1a 抓"N 字/趋势延续的结构性破位"；T1b 恢复强趋势连续新高/新低（摆动位全破、`ref=None`）时的追势入场——2026-09-27 追高复盘里"跳过 T1 判定落回金K分支"的临时口径，于 2026-09-29 改为独立类型与结构突破并存（复盘分组对比胜率）。

两类共享 §4 全部闸门；T1b 命中同样写 `breakout_events`（回测位 = 轨价）、同样按 `_close_op` 处置 pending（supersede 理由同为 `"breakout"`）。

### 3.3 判定流程速览

```
solid? ──否──────────────────────────────→ 跳过 T1，进金K/触点矩阵
  │是
  ├─ 结构位 ref = 未破前高/前低
  │    ├─ ref 命中 且 thr ≤ 越位 ≤ max → T1a 触发，return
  │    └─ 否则（无未破位/幅度不达/超幅）
  └─ n ≥ chan_n+2 且 thr ≤ 越轨 ≤ max → T1b 触发，return
                                         否则进金K/触点矩阵
```

## 4. 共享闸门（T1a/T1b 通用）

### 4.1 最小突破幅度

- 参数：`flt.breakout_threshold`，默认 `settings.BREAKOUT_THRESHOLD = 0.002`（0.2%）；
- 收盘价须越过突破位（前高/前低/轨价）至少 0.2%，毛边突破不算。

### 4.2 追高上限

- 参数：`flt.breakout_max_pct`，默认 `settings.BREAKOUT_MAX_PCT = 1.5`；`0 = 关闭`；
- 收盘越位 > 1.5% 视为追高、不产生突破触发（2026-09-27 正式网复盘 B 项）；
- T1a 按前高/前低、T1b 按轨价各自衡量——同一根K线对结构位是追高、对滚动轨可能是正常突破（强趋势逐根推进天然贴近轨价，test_trigger_two_stage.py:523-535）。

### 4.3 长实体门（BREAKOUT_BODY_RANGE_MIN = 0.70）

`_is_solid_breakout_candle`（`trigger.py:98-119`）：

- **顺向实体**：做多要求阳线（close>open）、做空要求阴线（close<open）；
- **长实体**：`|close-open| / (high-low) ≥ 0.70`——实体占据 K 线主体，影线合计 ≤30% 即天然短影线，**不做单侧影线额外限制**；
- `rng ≤ 0` 或 `body ≤ 0`（纯十字）直接拒绝。

演进：2026-09-25 收紧（要求近光头光脚）→ 2026-09-28 放宽为"主体占比即影线约束"（HUMA 个案：影线略长但结构强的突破不再被拒）→ 2026-09-30-2 实体门 0.75 → 0.70 再放宽。

同口径副本（**2026-10-10-4 起解除同步**）：`candlestick.TREND_CANDLE_BODY_RANGE_MIN = 0.60`（趋势K线，供"锤+趋势K"复合确认——回踩反转根常带探底下影，证据层放宽；突破K线维持 0.70），复制常量避免 strategy 内部反向 import trigger，**两常量此后各自独立改版**。

### 4.4 放量加分（非硬门）

- 量比口径：`indicators.volume_ratio`（`indicators.py:33-46`）= 信号K线量 ÷ 近 20 根已收盘**中位**量（2026-09-29 由算术均值改中位数，抗插针扫量/公告量堆的极值抬升；需 ≥22 根已收盘，否则返回 0）；
- `vr ≥ flt.breakout_vol_ratio`（默认 1.2，`BREAKOUT_VOL_RATIO`）时 reason 前缀 `放量{vr:.1f}倍·`；不达标则无此前缀（测试断言 `放量 not in reason`）；
- **2026-09-29 起放量为加分项不卡死**：缩量突破照常触发，但质量分不加（`compute_quality_score` 中三类触发统一 `量比 ≥1.2 +5`，`technical.py:709-717`），排序自然落后。

## 5. 回踩两段式（trigger_pullback_confirm）

### 5.1 触点体系（6 类优先级）

代码：优先级常量 `TOUCH_ORDER`（`trigger.py:78`，与 `scan_filters.ALL_TOUCH_REFS` 同源顺序）；探测器 `_detect_retest`（`trigger.py:430`）、`_detect_swing_touch`（`trigger.py:485`）、`_detect_ema_touch`（`trigger.py:266`）；并行探测并入 `detect_trigger`（`trigger.py:558`）。

| 优先级 | touch_ref | 中文标签 | 语义 | 门控 |
| --- | --- | --- | --- | --- |
| 1 | `retest` | 突破回测位（前高/前低） | T1 破位价的回踩不破 = 突破有效性确认 | 方向一致 + 事件窗口 + 带宽触碰 |
| 2 | `swing` | 摆动结构位 | 最近 3 个 HL（多）/LH（空）候选防守位，任一满足触碰即命中 | 只认结构延续标签 + 时效门 + 带宽触碰 |
| 3 | `ema21` | EMA21 | 趋势动态价值区（原口径） | 无门（行为与 docs/19 完全一致） |
| 4 | `ema55` | EMA55 | 中回撤 | 数据门 + 排列门 + 斜率门 |
| 5 | `ema144` | EMA144 | 深回撤 | 数据门 + 走平/顺势门 + 4h 上下文门（`htf_dir` 缺失即不出，2026-10-16 复出） |

各探测器判定细节：

- **retest**（`_detect_retest`）：① 方向一致（反向破轨事件对当前候选无效）；② 事件K线开盘须落在最近 `retest_window_bars`（默认 24）根已收盘K线内（越久回测语义越弱；`window_bars=0` 关闭该触点）；③ 带宽触碰：多头 `low ≤ lvl×(1+band)` 且 `close ≥ lvl`（影线可下插入带、**收盘须守住**——收盘破位 = 突破失败，不构成回测），空头对称。
- **swing**（`_detect_swing_touch`）：`recent_swings(klines, order=swing_order, n=10)`（阶数跟随「摆动点阶数」配置，默认 3，2026-10-12），多头只认 `HL`（更高低点）、空头只认 `LH`——`LL/HH` 不构成回踩结构（是接刀/追高）；**取最近 3 个同向结构位候选**（2026-10-16 用户拍板：最近 1 个可能因当前窗口 `merge_swings` 合并而消失（不稳）、第 2 个为常规防守位、第 3 个兜底），按新→旧顺序返回最先满足触碰者；时效门 `bars_ago ≤ SWING_MAX_BARS_AGO = 40`（防守点太老防守意义衰减）；带宽触碰与 retest 同口径（`structure_touch_band_pct` 默认 0.3%）。
- **ema21**：触点判定无门，多头 `low ≤ EMA21 ≤ close`（下影触及且收盘收回线上）、空头 `close ≤ EMA21 ≤ high`（上影反抽受阻且收盘收回线下）；**命中后须过 1H 结构门**否则本次回踩否决（2026-10-12，§5.6）。
- **ema55 三道门**（防"把震荡当回踩"）：① **数据门**：已收盘根数 `< max(ema_touch_min_bars, 周期×1.7)` 静默跳过——EMA 收敛需要窗口；② **排列门**：多头要求快线在慢线上方（`ema21>ema55`）——慢线之下还有快线托着才是趋势回踩；③ **斜率门**：被触碰 EMA 近 5 根同向（多头 `e[-1] > e[-6]`，走平的慢线是震荡盘整）。
- **ema144 数据门 + 走平/顺势门 + 4h 上下文门**（2026-10-16 复出并默认启用）：① **数据门**同 ema55（周期×1.7≈245 根，扫描链 `limit=max(kline_window,300)` 已满足，无需提窗）；② **走平/顺势门**：1h EMA144 近 `SLOPE_BARS=20` 根变化 ≥0（走平或向上）当 4h 为多、≤0 当 4h 为空——4h 方向由 scanner `gate_4h` 经 `htf_dir` 传入（`gate_4h` 已强制与多数决方向一致）；③ **4h 上下文门**：`htf_dir=None`（4h 拉取失败/gate 异常降级）时 fail-closed 不出该触点——不用 1h 方向冒充 4h 方向（2026-10-16 加固）；**不叠加排列门**（`ema55>ema144` 在深回撤时常先杀，正是 2026-10-10 退役主因）与 5 根严格斜率门（走平不再被拒）。

- **同根多触点命中按优先级标注**（横向结构语义强于均线；均线取最快——最早确认、止损最紧）：`touch_ref = next((r for r in TOUCH_ORDER if r in touches), None)`，命中的位价随 `ema21` 键进 pending、随 reason 展示。
- 触点白名单 `flt.pullback_touch_refs` 控制启用项，默认开启 swing + 均线族四触点（`swing/ema21/ema21_4h/ema55/ema144`；retest 默认关，须配置弹窗显式勾选）——各类由门控自筛：retest 无破轨事件/结构越位自然不命中，ema55 有三道门，ema144 有走平/顺势门。

### 5.2 pending 生命周期

pending 持久化于 `pullback_pendings` 表（模型 `PullbackPending`），scanner 每轮批量预取活跃行（`_prefetch_pendings`，scanner.py:626-657，每轮一次查询勿逐币查；同 symbol 取最新一条防并发双行），扫描线程只读快照，处置动作统一落库（`_apply_pending_ops`，scanner.py:759-827）。

- **有效期判定**（`trigger.py` pending 窗口块）：`pending.stage1_candle_open` 须落在信号K线之前 **1..N 根已收盘K线**内（N=`ScanFilters.pending_confirm_window_bars`，默认 3；逐根比对开盘时间）——窗口内即有效，免疫扫描时刻漂移与轮次缺失；超 N 根或找不到锚点的 pending 一律失效。N=1 时语义与旧「恰好 `klines[-3]`」口径等价。
- **upsert**（行5，`trigger.py:511-518`）：触碰无金K → `{"op": "upsert", direction, touch_ref, stage1_candle_open=<信号K线开盘>, ema21=<触点位价>}`（`ema21` 键存 Stage-1 锚点价，历史命名）。scanner 侧补 `quality_score`（按 `PULLBACK` 历史口径计）与 `votes_json` 快照（scanner.py:216-221）。落库语义（scanner.py:782-806）：同方向刷新锚点续命（锚点换新触碰根、等待窗口重新计时）；无活跃行则新建；方向反转旧行 expired(direction_flip) 后同事务新建（保留审计链，不原地改写方向）。
- **confirm**（行3）：窗口内确认（触碰根后 1..N 根内出现同向金K）→ `{"op": "confirm"}`；scanner 终态 `confirmed`，回填 `confirm_pattern` 与 `confirmed_scan_result_id`（关联本轮新写入的 ScanResult，scanner.py:809-812）。若 Stage-1 触点是 retest，同时将破轨事件 consume（scanner.py:381-384）；当根确认命中 retest 触点同样 consume（scanner.py:386-389）。
- **supersede**：被同方向更强触发（T1 突破 / 当根确认）抢先 → 终态 `superseded`（reason `breakout` / `same_candle_confirm`）。
- **expire**：方向反转 `direction_flip`（死因是票崩而非被抢先）或窗口过期 `window_expired` → 终态 `expired`（scanner.py:818-821）。行6/行7 中"无效 pending 也顺手终态（错过即过期）"（`trigger.py:520-523`）。
- **前置过期路径**：票数不足/4h 震荡/4h 方向冲突时，scanner 在进入 `detect_trigger` 之前直接对活跃 pending 发 `expire(direction_flip)`（scanner.py:162-199）——pending 仅在方向与多数决一致时有意义。

状态机速览：

```
(无 pending) --触碰无金K--> [pending] --窗口内(1..N根)出现金K--> (confirmed，产生 PULLBACK_CONFIRM 信号)
     ↑                          |      --T1 突破/当根确认抢先（同向）--> (superseded)
     └── 反向 expire 后同事务重建 ──┤      --方向反转--> (expired: direction_flip)
                                     --窗口(1..N根)耗尽无金K--> (expired: window_expired)
```

### 5.4 金K复合确认（resolve_golden_evidence）

裁决顺序（wanted = 方向票多数决方向，`"bullish"`/`"bearish"`）：

1. **非单影线金K直通**：当根形态 ∈ GOLDEN_12 且 ∉ SINGLE_SHADOW_PATTERNS（吞没/启明星/黄昏星/**锤形线**）方向匹配 → 直接确认，note = ""。2026-10-01 拍板：单锤恢复单根直通（探底回升语义足够强），复合确认仅剩流星线；复合形态（吞没/启明星/黄昏星）本身由多根K线构成、结构更强，维持单根确认。**2026-10-01-2 拍板：倒锤形线退出看涨白名单**（线上 KSMUSDT 回踩 EMA21 匹配倒锤个案）——看涨回踩语境里倒锤的长上影 = 反抽遭上方抛压打回，不是支撑企稳证据；支撑企稳只认长下影锤形线。

### 5.5 量能注记（docs/25 §3.1）

## 7. 指标方向票与上游门（衔接 01 文档）

触发器不判方向。上游 `scanner.detect_indicator_candidate`（scanner.py:210-320，定时扫描与 watchlist.refresh 共用）的管线：

1. **4h 趋势闸门 gate_4h 前置**（2026-10-10 二次拍板）：EMA144 斜率 ≥0.5%/20 根、近 10 根缠绕 ≤2 次、ADX≥20 三者**同时成立**才放行，任一命中直接否决（不跑票数/触发/候选），活跃 pending 同轮 `expire(ranging)`；`htf_state_lock`（4h 状态机双向禁开）紧随其后作第二道前置门（2026-10-13 拍板）；
2. **方向票（拆角色，docs/21 O9）**：`compute_indicator_votes(klines, htf_bg=htf_res)` 单趟算完全部指标，**方向票仅 1h 三张——MACD / 布林带 / RSI**（`technical.DIR_VOTE_SHORTS`）；ADX/OBV/SuperTrend 与 4h 背景**退出方向票**，其 `dir` 仍计算并写入 `votes_json` 供展示/AI/质量分用（4h 背景复用第一步结果，不双算）；
3. **方向票门槛**：`max(bull_n, bear_n) ≥ DIR_VOTE_MIN`（同向 ≥2 张）才有方向，`direction = 1 if net > 0 else -1`；不足则中性跳过，活跃 pending 按方向失守过期（`expire(direction_flip)`）。原「`|net| ≥ 3` 且 `voted ≥ 5`（7 票净差）」门槛已退役——滞后指标主导 1h 方向、net 因票集过大虚高；
4. **闸门方向一致性门**：4h 有方向（long/short）时 1h 方向必须一致——4h 看多只产生多头信号，与 4h 冲突的活跃 pending 按方向失守过期（htf 拉取失败降级时跳过）；
5. **震荡评分卡 range_score**：8 项独立评分 ≥3 不入场（前置门全过时实际杀伤力来自 1h ADX<18 预警 / 布林带收口 / 反复穿越 EMA21 / 量 CV<0.3 四项），pending `expire(range_score)`；
6. **触发确认**：调用 `detect_trigger(klines, direction, pending, flt=flt, retest=retest, htf=htf)`；
7. **白名单过滤**：命中触发类型 ∉ `flt.allowed_triggers` → 不产生候选（pending 处置照常执行，破轨事件照常记录）；
8. **质量分**：`compute_quality_score(direction, votes, trig_type, klines, structure_gate=...)`（technical.py）：`50 + direction×net×10` 基础（**2026-10-15 O9 rescale**，net=方向票净差∈{1,2,3}→基础 60/70/80）+ 4h 同向（强+10/弱+5）反向（强-12/弱-8）+ 突破且 ADX≥25 +5 + 放量 ≥1.2 +5 - RSI 追高（>75 做多 / <25 做空）-8 - OBV 背离 -6 - **SuperTrend 逆向 -6**（辅助票风险扣分）- 突破且布林带宽分位 ≤10 -5 - **1H 结构门未过 -15**（`structure_gate=False`，仅 ema21 触点）+ 回踩企稳加分项，封顶 [0,100]。

## 9. 数据模型与测试覆盖

### 9.1 数据模型（backend/app/models/scan.py）

- **ScanResult**：落库命中。触发器相关列：`signal_type`（=触发类型常量）、`pattern`（金K形态 key）、`touch_ref`/`position_ref`（触点类型与「回踩{触点}」位置文案）、`position`（support/resistance）、`breakout_pct`（突破路径为实际越位 %，回踩路径 0.0）、`quality_score`、`votes_json`（票数快照，含 `htf` 子对象供前端「4h方向」列）、`signal_reason`（截断 120 字）、`strength`（= quality_score/100）。
- **PullbackPending**（pending 池）：`status ∈ {pending, confirmed, superseded, expired}`；`direction`、`stage1_candle_open`（Stage-1 触碰锚点 = 触碰根开盘时间，有效期判定锚）、`ema21`（历史命名的 Stage-1 触点位价）、`touch_ref`（触点类型）、`quality_score`/`votes_json`（Stage-1 快照，按 PULLBACK 口径）、`confirm_pattern`、`confirmed_scan_result_id`（确认时回写关联）、`resolve_reason`（direction_flip / window_expired / breakout / same_candle_confirm）、`resolved_at`。
- **BreakoutEvent**（破轨事件，retest 事实源，docs/22 §4）：`status ∈ {active, consumed, expired}`；`direction`、`level_price`（= trigger 返回的 `breakout_level`：前高/前低/轨价）、`candle_open`（信号K线开盘）。处置：T1 触发 upsert（同方向刷新位价与锚点；反向破轨旧行 expired 后新建）、回踩金K命中 retest 触点 consume（当根/次根确认两条路径都消费）、active 且 `candle_open` 早于 `retest_window_bars` 根前批量 expired（scanner.py:702-757；落库失败整体回滚忽略——派生事实，下轮 T1 触发会重新记录）。
