# 币种筛选信号策略逻辑文档

> 版本：v2.0  
> 日期：2026-09-08  
> 适用周期：**1 小时 K 线（1h）**  
> 窗口长度：240 根（约 10 天）

---

## 1. 概述

本系统基于**摆动点结构分析（Swing Point Analysis）**识别币安 USDT 现货币种的三种交易信号：

| 信号类型 | 标识 | 中文标签 | 交易含义 |
|---------|------|---------|---------|
| 下跌趋势突破 | `downtrend_breakout` | 🔴 下跌突破 | 下跌趋势结束，可能反转向上 |
| 区间震荡 | `range_bound` | 🟠 区间震荡 | 价格在区间内震荡，接近下沿或突破上沿 |
| 上涨趋势回调 | `uptrend_pullback` | 🟢 上涨回调 | 上涨趋势中健康回调，可能延续上涨 |

所有策略共享同一套摆动点识别与结构分类工具，策略间互斥判断，一个币种可同时命中多种信号。

---

## 2. 基础工具：摆动点与结构识别

### 2.1 摆动点识别（`find_swing_points`）

**目的**：从 K 线序列中提取局部高点（摆动高点）和局部低点（摆动低点）。

**算法**：
- 对每根 K 线 `i`，取其左右各 `order` 根（默认 `order=3`）作为比较窗口。
- **摆动高点**：`highs[i]` 严格大于左侧窗口和右侧窗口的所有最高价。
- **摆动低点**：`lows[i]` 严格小于左侧窗口和右侧窗口的所有最低价。

**约束**：K 线数量需 ≥ `2 * order + 1`，否则无法形成摆动点。

```
摆动高点示意（order=2）：
        H
       / \
      /   \
  ---       ---
   i-2 i-1  i  i+1 i+2
```

### 2.2 摆动点合并（`merge_swings`）

**目的**：将摆动高点和摆动低点按时间排序，并过滤掉连续同类型的极值。

**处理**：
- 合并所有 H/L 点，按索引排序。
- 若出现连续两个 H，保留价格更高的那个；若连续两个 L，保留价格更低的那个。
- 最终得到 H、L 交替的摆动序列。

### 2.3 结构分类（`classify_structure`）

**目的**：分析摆动点序列，统计四种结构特征并判断趋势方向。

**四种结构定义**：

| 缩写 | 全称 | 含义 | 判定条件 |
|------|------|------|---------|
| **HH** | Higher High | 更高的高点 | 当前摆动高点 > 前一个摆动高点 |
| **LH** | Lower High | 更低的高点 | 当前摆动高点 < 前一个摆动高点 |
| **HL** | Higher Low | 更高的低点 | 当前摆动低点 > 前一个摆动低点 |
| **LL** | Lower Low | 更低的低点 | 当前摆动低点 < 前一个摆动低点 |

**趋势方向判定**（基于最近 4 个摆动点中的最近 2 个 H 和 2 个 L）：

| 条件 | 趋势 |
|------|------|
| 最近 H 抬高 且 最近 L 抬高 | `up`（上涨） |
| 最近 H 降低 且 最近 L 降低 | `down`（下跌） |
| 其他 | `range`（震荡） |

### 2.4 线性回归（`linear_regression`）

对摆动点的索引-价格做最小二乘线性回归，返回：
- `slope`：斜率（正=上升，负=下降）
- `intercept`：截距
- `r_squared`：拟合优度 R²（0~1，越大拟合越好）

## 3. 策略一：下跌趋势突破（downtrend_breakout）

### 3.1 信号含义

价格经历一段下跌趋势后，**打破下跌结构**（出现 HH 或突破下跌趋势线），预示趋势可能反转向上。

### 3.2 判定流程

#### 前置条件
- K 线数量 ≥ 30
- 摆动点总数 ≥ 4
- 摆动高点数 ≥ 3 且 摆动低点数 ≥ 3

#### 条件 1：确认下跌趋势
取最近 3 个摆动高点和最近 3 个摆动低点：
- `is_lh_sequence`：最近 3 个摆动高点**连续下移**（LH 序列）
- `is_ll_sequence`：最近 3 个摆动低点**连续下移**（LL 序列）
- 需满足 `is_lh_sequence OR is_ll_sequence`

#### 条件 2：拟合下跌趋势线
用最近 3 个摆动高点做线性回归：
- `slope < 0`（确为下跌趋势线）
- `r_squared ≥ 0.5`（拟合质量达标）

计算趋势线在当前位置的预测值 `trend_value`：
```
trend_value = slope * (n - 1) + intercept
```
- `trend_value > 0` 且 `trend_value ≥ close_last * 0.1`（排除异常小值）

#### 条件 3：突破判定（满足任一）

**方式 A — 趋势线突破**：
```
breakout_pct = (close_last - trend_value) / trend_value
broke_trendline = breakout_pct ≥ 0.005 (0.5%)
```

**方式 B — 结构突破（HH 打破 LH）**：
```
formed_hh = highs_seq[-1] > highs_seq[-2]
```
即最近一个摆动高点高于前一个摆动高点，LH 序列被打破。

#### 异常过滤
- `breakout_pct > 5.0`（500%）视为异常，过滤。

### 3.3 结构重点

> **核心关注 LH 序列被打破**：当下跌趋势中连续出现更低的高点（LH），一旦出现第一个更高的高点（HH），说明下跌动能减弱，是趋势反转的早期信号。

### 3.4 强度评分

| 条件 | strength |
|------|----------|
| 同时满足 formed_hh 和 broke_trendline | 1.0 |
| 仅 formed_hh | 0.7 |
| 仅 broke_trendline | 0.5 |

### 3.5 输出字段

| 字段 | 说明 |
|------|------|
| `signal_type` | `downtrend_breakout` |
| `current_price` | 最新收盘价 |
| `breakout_pct` | 突破幅度（%） |
| `trend_slope` | 下跌趋势线斜率（负） |
| `r_squared` | 趋势线拟合优度 |
| `formed_hh` | 是否形成 HH |
| `broke_trendline` | 是否突破趋势线 |
| `strength` | 信号强度 0~1 |

## 4. 策略二：区间震荡（range_bound）

### 4.1 信号含义

价格在上下边界之间震荡运行，当前接近区间下沿（潜在低吸机会）或已突破上沿（潜在向上突破）。

### 4.2 判定流程

#### 前置条件
- K 线数量 ≥ 30
- 摆动点总数 ≥ 5
- 摆动高点数 ≥ 3 且 摆动低点数 ≥ 3

#### 条件 1：识别震荡结构
取最近 5 个摆动高点拟合**上边界**，最近 5 个摆动低点拟合**下边界**。

将斜率归一化为相对斜率（消除价格量级影响）：
```
rel_slope = |slope| / price_range * n
```
其中 `price_range = highs.max() - lows.min()`

满足以下任一：
- **水平震荡**：`rel_slope_h < 0.005` 且 `rel_slope_l < 0.005`（上下边界接近水平）
- **收敛三角形**：`slope_h < 0` 且 `slope_l > 0`（上边界下行 + 下边界上行，即 LH + HL）

#### 条件 2：有效区间
计算当前上下边界位置：
```
upper_now = slope_h * (n-1) + intercept_h
lower_now = slope_l * (n-1) + intercept_l
```
- `upper_now > lower_now > 0`
- 区间宽度 `band_width / lower_now ≥ 0.005`（排除过窄区间）

#### 条件 3：位置判定（满足任一）
```
position = (close_last - lower_now) / band_width   # 0=下沿, 1=上沿
```
- **接近下沿**：`position ≤ 0.3`（潜在低吸）
- **突破上沿**：`(close_last - upper_now) / upper_now ≥ 0.005`（潜在向上突破）

#### 条件 4：波动率收敛
```
volatility_ratio = late_range / early_range
```
`late_range` 为后半段振幅，`early_range` 为前半段振幅。`volatility_ratio < 1.0` 表示波动率收敛，震荡蓄力。

### 4.3 结构重点

> **核心关注 LH + HL 的收敛结构**：当高点不断降低（LH）而低点不断抬高（HL），形成收敛三角形，预示变盘临近。水平震荡则关注价格触及下沿或突破上沿的时机。

### 4.4 强度评分

| 条件 | strength |
|------|----------|
| 突破上沿 + 水平震荡 | 1.0 |
| 接近下沿 + 波动率收敛 | 0.8 |
| 接近下沿（无收敛） | 0.5 |
| 突破上沿（收敛三角形） | 0.6 |

### 4.5 输出字段

| 字段 | 说明 |
|------|------|
| `signal_type` | `range_bound` |
| `current_price` | 最新收盘价 |
| `breakout_pct` | 相对下沿的涨幅（%） |
| `upper_band` | 当前上边界价格 |
| `lower_band` | 当前下边界价格 |
| `band_position` | 价格在区间中的位置（0~1） |
| `volatility_ratio` | 后期/前期振幅比 |
| `is_converging` | 是否为收敛三角形 |
| `strength` | 信号强度 0~1 |

## 5. 策略三：上涨趋势回调（uptrend_pullback）

### 5.1 信号含义

价格处于上涨趋势中，出现健康回调但未破坏上涨结构，是趋势延续中的低吸机会。

### 5.2 判定流程

#### 前置条件
- K 线数量 ≥ 30
- 摆动点总数 ≥ 4
- 摆动高点数 ≥ 3 且 摆动低点数 ≥ 3

#### 条件 1：确认上涨趋势
取最近 3 个摆动高点和最近 3 个摆动低点：
- `is_hh_sequence`：最近 3 个摆动高点**连续上移**（HH 序列）
- `is_hl_sequence`：最近 3 个摆动低点**连续上移**（HL 序列）
- 需满足 `is_hh_sequence OR is_hl_sequence`

#### 条件 2：拟合上升趋势线
用最近 3 个摆动低点做线性回归：
- `slope > 0`（确为上升趋势线）
- `r_squared ≥ 0.5`

趋势线当前值：
```
trend_value = slope * (n - 1) + intercept  (> 0)
```

#### 条件 3：回调判定（满足任一）

**方式 A — 回调到趋势线附近**：
```
distance_to_trend = (close_last - trend_value) / trend_value
near_uptrend_line = 0 ≤ distance_to_trend ≤ 0.03
```
价格在趋势线上方 0~3% 范围内。

**方式 B — 回调到近期 HL 附近**：
```
last_low = recent_lows[-1]
distance_to_hl = (close_last - last_low) / last_low
near_hl = 0 ≤ distance_to_hl ≤ 0.03
```
价格在最近摆动低点上方 0~3% 范围内，未跌破前低。

**方式 C — 回调幅度合理**：
```
pullback_depth = (recent_high - close_last) / recent_high
reasonable_pullback = 0.02 ≤ pullback_depth ≤ 0.15
```
从近期高点回调 2%~15%。

#### 条件 4：未跌破趋势线
```
distance_to_trend ≥ -0.03
```
回调不能跌破上升趋势线超过 3%，否则趋势可能已破。

### 5.3 结构重点

> **核心关注 HL 序列保持**：上涨趋势中回调必须不破前低（HL 继续抬高）。若回调跌破前低，则上涨结构破坏，信号失效。回调幅度控制在 2%~15% 为健康回调，过深则可能转势。

### 5.4 强度评分

| 条件 | strength |
|------|----------|
| 回调到趋势线 + 回调幅度合理 | 1.0 |
| 回调到趋势线 或 回调到 HL 附近 | 0.7 |
| 仅回调幅度合理 | 0.5 |

### 5.5 输出字段

| 字段 | 说明 |
|------|------|
| `signal_type` | `uptrend_pullback` |
| `current_price` | 最新收盘价 |
| `breakout_pct` | 距趋势线的距离（%） |
| `trend_slope` | 上升趋势线斜率（正） |
| `r_squared` | 趋势线拟合优度 |
| `pullback_depth` | 从高点回调幅度（%） |
| `distance_to_trend` | 距趋势线距离（%） |
| `strength` | 信号强度 0~1 |

## 6. 配置参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `KLINE_INTERVAL` | `1h` | K 线周期 |
| `KLINE_WINDOW` | `240` | 获取的 K 线数量 |
| `SWING_ORDER` | `3` | 摆动点左右比较根数 |
| `BREAKOUT_THRESHOLD` | `0.005` | 突破阈值（0.5%） |
| `R_SQUARED_THRESHOLD` | `0.5` | 趋势线拟合优度下限 |
| `PULLBACK_TOLERANCE` | `0.03` | 回调容差（3%） |
| `max_trend_slope` | `0.005` | 震荡区间斜率上限（相对值） |
| `min_klines` | `30` | 最少 K 线数量 |

## 7. 三种信号对比

| 维度 | 下跌突破 🔴 | 区间震荡 🟠 | 上涨回调 🟢 |
|------|-----------|------------|------------|
| 前置趋势 | 下跌（LH+LL） | 震荡/收敛 | 上涨（HH+HL） |
| 趋势线 | 下跌趋势线（高点拟合） | 上下边界 | 上升趋势线（低点拟合） |
| 触发条件 | 突破趋势线 或 形成 HH | 接近下沿 或 突破上沿 | 回调到趋势线/HL 附近 |
| 结构焦点 | LH 被打破 → HH | LH + HL 收敛 | HL 保持不破 |
| 交易方向 | 做多（反转） | 做多（下沿）或突破跟进 | 做多（趋势延续） |
| 风险等级 | 中高（抄底反转） | 中低 | 中（顺势回调） |

## 8. 执行流程

```
K 线数据（1h × 240）
        │
        ▼
  摆动点识别（order=3）
        │
        ▼
  合并为 H/L 交替序列
        │
        ▼
  ┌─────┴─────┬─────────────┐
  ▼           ▼             ▼
下跌突破    区间震荡     上涨回调
(LH+LL)    (水平/收敛)   (HH+HL)
  │           │             │
  ▼           ▼             ▼
拟合趋势线  拟合上下边界  拟合上升趋势线
  │           │             │
  ▼           ▼             ▼
突破判定   位置+波动率   回调判定
  │           │             │
  └─────┬─────┴─────────────┘
        ▼
    输出命中信号（可多个）
```

## 9. 边界处理

| 场景 | 处理 |
|------|------|
| K 线 < 30 根 | 跳过 |
| 摆动点 < 4 个 | 跳过 |
| 摆动高/低点 < 3 个 | 跳过 |
| 趋势线 R² < 0.5 | 拟合差，跳过 |
| 趋势线值 ≤ 0 或过小 | 跳过 |
| 突破幅度 > 500% | 异常值，跳过 |
| 数值 NaN/Inf | 跳过 |
| 币安 API 请求失败 | 记录日志，跳过该币种 |

## 10. 后续优化方向

1. **多周期确认**：1h 信号 + 4h 趋势方向过滤，提高胜率。
2. **成交量确认**：突破时伴随放量，增加可信度。
3. **动态参数**：根据币种波动率自适应调整 `swing_order`、突破阈值。
4. **回测框架**：历史数据回测各策略胜率与盈亏比。
5. **信号去重**：同一币种多信号命中时按 strength 排序，只取最强信号。
