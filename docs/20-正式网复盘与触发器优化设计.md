## 2. 结论：赚亏分界 = 入场位置，不是环境

- **正期望路径**：回踩系入场（价格贴近 EMA21）+ trail 跟随 → 趋势日吃肉
- **负期望路径**：悬空金K / 大幅突破追高 → 震荡日连损，趋势日的利润被回吐

## 3. 三项优化（A/C/B，均可配置回滚）

### A. 悬空金K距离门槛（证据最强）

- **改动**：`trigger.py` T2 纯金K分支——信号K线收盘距 EMA21 > 阈值 → 不产生候选；
  row3 次根确认有回踩语境（上根触碰 EMA21），前置判定不受影响；
  活跃 pending 按方向反转（direction_flip）/ 窗口过期（window_expired）正常处置
- **配置**：`CANDLE_MAX_EMA21_DIST_PCT = 1.5`（0=关闭）
- **取舍**：趋势日悬空金K偶有赢家（BB/FET 两笔 tp1_trail +24），1.5% 宽松起步，宁可少亏不追求全禁

### C. 当日亏损熔断（替代原「震荡日降频」提案）

- **改动**：`trade_engine.try_open_for_analysis` 余额闸门后——UTC 日本账号已平仓
  净亏 ≤ -阈值 → 跳过开仓，`open_block_reason=「当日亏损熔断」`；
  查询抽成 `_daily_closed_pnl`（账号口径：account_key 匹配 + NULL 按 testnet 回落，
  与在跑单检查一致）
- **配置**：`DAILY_LOSS_STOP_USDT = 30`（≈ 3.3 笔满损 / 钱包 10%；0=关闭）
- **边界**：只停开仓——AI 分析照常跑（保持观察）、结算巡检/诊断不受影响；
  `_attempt_open` 唯一调用方即 try_open_for_analysis，无绕过路径
- **数据**：09-26 全天 13 笔全灭仍持续开单；熔断在第 3 笔满损即止血

### B. 突破幅度上限（追高拦截）

- **改动**：`trigger.py` T1 分支——满足下限 0.2% 但越过轨 > 上限 → 跳过突破判定，
  落回金K/回踩分支自然过滤（突破长实体通常非金K → 无候选）；
  趋势日后续回踩 EMA21 + 金K 由 T3 接住，不缺席
- **配置**：`BREAKOUT_MAX_PCT = 1.5`（0=关闭）

## 4. 评审过但不做项

| 提案 | 裁决理由 |
|---|---|
| 4h 震荡日限制开单频率 | ranging 仅 2 笔，数据不支持；真实病根是入场位置（§1.4/§2） |
| 突破要求 4h 强趋势同向 | 强多同向背景下突破 11 笔 2 胜 -0.26R，强背景救不了突破 |
| 恢复一段式回踩（trigger_pullback） | +116.53 集中在 09-25 趋势日（09-23/24 也亏），行情馈赠非触发器 alpha，且已下线 |
| 滑点闸门收紧 | max_slippage_pct=0.3% 已在，7 笔 ≥0.2% 带内正常；平均滑点 0.054% |
| 止损宽度规则调整 | §1.7 数据反向（宽止损 R 更优），样本不足不动 |
