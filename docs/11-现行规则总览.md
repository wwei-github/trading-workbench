## 3. AI 提示词纪律（**提示词纪律**——程序不校验，AI 自觉遵守）

> 以下方法论写在 ai_analyzer / ai_agent 系统提示词中；2026-09-15 起对应程序校验已全部移除，AI 是否遵守由复盘结果间接检验。

| # | 纪律 | 内容 |
|---|---|---|
| 3.1 | 方向纪律 | 优先只在支撑结构做多、只在压力结构做空；现价已离开结构位时不强制贴近，可顺势按动能给入场价 |
| 3.2 | 止损锚定 | 结构锚优先（入场价同侧最近摆动点外 0.3%~0.5%）vs 最近 5 根影线极值，**两锚取更远者**；止损放进近期波动区间内部视为会被扫损 |
| 3.3 | 止盈锚定 | 距现价 ≤1×ATR 的"争夺位"不作止盈目标；止盈一挂更远的第一档摆动结构位外侧留 0.2%~0.5% 余地；止盈二取下一档且必须更远；**禁止跳档凑盈亏比**（到第一结构位不足 1.5 应直接 skip）；创新高/新低前方无结构位时止盈一 = 入场 ± 1.5×止损距离、仅设一档 |
| 3.4 | 开单类型三分类 | trend_follow 顺势（EMA 三线严格排列是硬前提）/ structure_break 结构破位回踩（123法则·N字结构·2B法则三子形态）/ range_edge 区间边缘反转；归为震荡区间的信号不用 structure_break |
| 3.5 | 输出格式 | analysis ≤300 字中文、"1. 2. 3."序号分点、先条件后风险再结论；skip_reason 最多 3 条 |
| 3.6 | 推荐度 | skip ≤30、suggest ≥50（程序侧会钳制） |
| 3.7 | 仓位不自报 | 程序按固定亏损法复算覆盖，AI 报的 position_pct 仅作估算 |

## 4. AI 决策校验链（**程序强制**，risk_guard）

> 2026-09-15 拍板收缩为两条：**RR 铁律 + 双评委辩论**。违规打回修正（1 次初始 + 2 次违规反馈重试），耗尽 → 强制 skip。

| # | 校验 | 强度 |
|---|---|---|
| 4.1 | Schema 归一化 + suggest 基本项：direction / trade_type 必填且合法，entry/sl/tp1 为正数价格；skip 时 skip_reason 必填 | 程序强制 |
| 4.2 | **RR 铁律：按 AI 三价复算盈亏比 ≥1.5**（声称值不信，复算值落库；止损距离为 0 直接打回） | 程序强制（唯一价格铁律） |
| 4.3 | **双评委辩论**：对 suggest 决策多空辩论复核，裁判只能 keep / veto（无权改价格方向），veto → 强制 skip。**默认开** | 程序强制，`dual_judge_enabled` ✅可配置，现值 **开**（每笔 suggest 多花 3 次 LLM 调用） |
| 4.4 | recommendation 钳制：suggest 钳到 50~100、skip 钳到 ≤30 | 程序强制（修正不回炉） |
| 4.5 | 固定亏损仓位复算：`position_pct = 3% ÷ 止损距离%`（不设 clamp，止损越远仓位越小） | 程序强制 |

## 5. 开仓闸门（**程序强制**，trade_engine）

> 触发前置：总开关 `TRADING_ENABLED`（env）、testnet 标识、决策为 suggest 且 **评分 ≥60**（`TRADING_MIN_RECOMMENDATION`）、分析落库 1 小时内、该分析未开过仓、**非"待回踩"**（入场价在现价回踩侧的建议仅展示"⏳ 待回踩"标识、不下单，2026-09-15）。
> trade_type **仅记录**（2026-09-15：策略开关不再拦截开仓）。

| # | 闸门 | 参数 |
|---|---|---|
| 5.1 | 在跑仓位 < 上限 | `max_open_trades` ✅可配置，现值 **10** |
| 5.2 | **可用余额 ≥ 总资金 × 比例**（钱包余额 − 在跑占用保证金；不满足则停止本轮开仓） | `trading_min_free_pct` ✅可配置，现值 **50%**（2026-09-15 由固定 70% 改为可配置） |
| 5.3 | 资金分档基数 > 0（钱包余额 ≥ 最低档 100 USDT，见 §6.1） | `TRADING_CAPITAL_TIERS`（env） |
| 5.4 | 同币种无在跑仓位 | — |
| 5.5 | 现价偏离 AI 入场 ≤1%（超出作废） | 硬编码 1% |
| 5.6 | trend_follow 专属：EMA 三线严格排列（多 21>55>144，空反之），开仓时按最新 K 线复核 | — |
| 5.7 | **强平闸门**：止损距离 < 1/杠杆 − 维持保证金率 = 4.5%（20×），止损过宽直接跳过；止损距离 = 0 放弃（防除零） | `TRADING_LEVERAGE=20`（env） |
| 5.8 | 交易所规则：qty ≥ min_qty / min_notional（不足放弃）；超 max_qty 按上限缩减（实际风险低于预算） | 交易所 exchangeInfo |
| 5.9 | TP1 分批数量下单前预检（低于 min_qty 整单放弃，防"开仓→挂单→回滚→平仓"空转） | — |
| 5.10 | 保证金可用性：所需保证金 ≤ 可用余额 | — |

## 6. 资金与仓位规则（**程序强制**）

| # | 规则 | 说明 |
|---|---|---|
| 6.1 | 风险基数分档：钱包余额（不含浮盈）**向下落到最近档位** | 档位 `100/200/500/1000/2000/5000/10000`（`TRADING_CAPITAL_TIERS`，env）。例：余额 730 → 基数 500 |
| 6.2 | **固定亏损法**：止损金额 = 基数 × **3%**；名义 = 止损金额 ÷ 止损距离%；qty = 名义 ÷ 现价 | `TRADING_RISK_PCT=3.0`（env）。触发止损时恰好亏"基数×3%" |
| 6.3 | 杠杆与保证金：**20× 逐仓（ISOLATED）**，margin = 名义 ÷ 20 | `TRADING_LEVERAGE=20`（env） |
| 6.4 | 止盈分批：TP1 = 仓位的 **50%**（AI 未给 TP2 时 **75%**）、TP2 = **25%**（须 ≥ 交易所 min_qty，不足静默只挂一档） | — |
| 6.5 | 下单序列：市价开仓 → 挂 SL（STOP_MARKET closePosition）→ 挂 TP1 → 挂 TP2；记录实际成交均价与滑点 | 滑点使实际风险 >1.15× 预算仅 WARNING 不拦截 |
| 6.6 | 失败回滚：任一挂单异常 → 撤全部 algo 单 + reduceOnly 紧急平仓，不留裸仓；-1121（未上架）落 FAILED 记录排除该币 | — |

## 7. 持仓管理（结算巡检，**程序强制**）

| # | 规则 | 说明 |
|---|---|---|
| 7.1 | 交易所为真相：以交易所持仓 + 挂单 algo ids 比对本地状态推进 | — |
| 7.2 | TP 事件推断：tp1/tp2 挂单消失 → 对应止盈事件；结算金额取 income 明细（REALIZED_PNL + COMMISSION + FUNDING_FEE） | 分档书签 `raw.realized_bookmark` |
| 7.3 | **TP1 成交 → 止损移保本**（幂等，每轮检查） | — |
| 7.4 | **跟进止损**（TP1 后无 TP2、或 TP2 已成交）：锚定最近 3 根已收盘 K 线极值（多单取最低），**只收紧不放松**；TP2_HIT 阶段多单止损钳制在 TP1 之上 | 巡检间隔 1h = 1 根 K 线 |
| 7.5 | SL 挂单丢失补挂：仓位存活而 SL 单不在挂单列表时按当前止损价补挂（现价已越过止损价则跳过，留结算路径确认） | — |
| 7.6 | **孤儿条件单清扫**：交易所在挂 algo 委托但既无持仓也无在跑记录的 symbol 一律撤销（只清本系统符号语境，不全账户无差别撤单） | 2026-09-15 新增 |
| 7.7 | 强平识别：income 中 `INSURANCE_CLEAR` 非零 → LIQUIDATION 事件、exit_reason=liquidation | 强平会撤全部挂单，不能凭 tp1 消失推断成交 |

## 8. 复盘（AI 建议质量回放，**程序强制**，不调 LLM）

| # | 规则 | 说明 |
|---|---|---|
| 8.1 | 对象：**所有 suggest 决策**（不论是否开单），分析落库 **24h** 后用 1h K 线逐根回放 AI 原始计划 | `OBSERVATION_HOURS=24` |
