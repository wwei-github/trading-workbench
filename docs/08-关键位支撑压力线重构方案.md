# 08 - 关键位支撑/压力线重构方案

> **状态**：2026-09-14 方案稿（待实施）
>
> **背景**：现行关键位是"区域"（中心价 ± ATR 自适应半宽，实际 ±0.15%~0.6%）。用户决定**彻底去掉区域概念**（zone_low/zone_high），重新开发关键位计算逻辑——支撑位/压力位为**单价格线**。
>
> **算法（已拍板）**：**摆动点聚合线**——最近摆动高/低点成线（前高/前低），历史摆动点价距 ≤0.5% 聚合为一条线（均值价、触及计数），角色由来源固定，每侧最多 5 条，图上水平线 + 触及次数标签。

---

## 1. 新算法规格

**入口**：`backend/app/services/strategy/key_levels.py` 核心重写，`compute_key_levels(klines, config)` 签名不变（图表端点、AI 事实包、`_detect` 共用，统一口径不变）。

### 1.1 摆动点与聚合

- 摆动点复用 `find_swing_points(order=swing_order)` + `merge_swings`（Pine 收盘价口径不动）；
- **角色由来源固定**：低点序列 → 支撑线（support），高点序列 → 压力线（resistance），**不再按现价动态互换**；
- 聚合（`_cluster_levels` 改名 `_aggregate_lines`，保持**链式**口径——候选点与组内最后一点比价距）：
  - ~~每侧**最新摆动点单独成线**（前高/前低，touches=1，不参与聚类）~~
    **修订（2026-09-14 傍晚）**：取消该例外——最新点与其余点一样参与聚合，价格相近的线
    一律融合为一条（用户反馈"线太多、相近线要融合"，上线后图上出现贴脸双线）；
  - 全部摆动点：与已有线价距 ≤ `level_merge_threshold`(0.005) 并入（重算均值价），否则自成新线；
  - 输出 `[(均值价, touches, pattern_hits, newest_idx)]`——**不算时间权重、无 MIN_CLUSTER_WEIGHT 门控**；
  - 每侧按 newest_idx（时间新→旧）截前 `LEVELS_PER_SIDE=3` 条（修订：5 → 3，全图 ≤6 条）。

### 1.2 输出字段（两侧合并按 price 升序）

```
{kind: "support"|"resistance", role: 同kind, price, touches: 成员数, pattern_hits: 形态确认数}
```

**删除**：zone_low/zone_high、weight、TOUCH_HALF_LIFE / MIN_CLUSTER_WEIGHT / PATTERN_TOUCH_BOOST / _touch_weight、RANGE_BOUND 回归边界分支、`_merge_overlapping_levels`、ATR 自适应半宽。

**保留不动**：`calc_atr`、`volume_ratio`、`fmt_price`、`_level_side`、`PATTERN_CONFIRM_WINDOW`、`BREAKOUT_VOL_RATIO`。新增 `DEFAULT_TOL=0.003`。`_pattern_boosts` 简化为 `_pattern_hit_idxs(swings, klines) -> set[int]`（摆动点当根+后2根内方向匹配12金K，去 ×1.5 乘数）。

### 1.3 触及 / 突破判定（固定容差带）

`find_touching_level` / `find_broken_level` 加参数 `tol: float = DEFAULT_TOL`（全站唯一调用方是 `_detect`，安全）：

- **触及** = 影线与 `[price×(1−tol), price×(1+tol)]` 相交 **且** 收盘在持住侧（`_level_side` 按 prev_close 判侧保留：support 侧收盘 ≥ price×(1−tol)、resistance 侧收盘 ≤ price×(1+tol)）；同分取距 price 最近；
- **突破** = 收盘越过 `price×(1±tol)`，**pct 从 price 算**（原从区域边缘算）；破位距离最大者；
- tol 取 `key_level_tolerance`(0.003)：判定容差语义，**不再烙进 level dict**。

`compute_key_levels` 不再调 `classify_structure`（signal_type 标签仍由 `_detect` 自算，structure.py 不动）。

## 6. 行为变化（需知悉）

| 变化 | 后果 |
|---|---|
| 指纹/3h沿用缓存含最近位 price | 部署后一轮全量 miss，AI 分析量瞬时抬升（一次性） |
| 触位带自适应 0.15%~0.6% → 固定 ±0.3% | 低波动币触位增多、高波动币减少，信号量按币种分化；突破触发点更贴线，放量突破略增 |
| 角色固定化 | 单边趋势市贴现价可入场位变少（"只在支撑做多/压力做空"更纯粹），方向铁律打回增多 |
| 止损锚 zone 边缘 → 线本身 | SL 平均更近 → 开仓量增大；0.3×ATR 下限更易触发回退极值锚 |
| 止盈锚区域近轨 → 线本身 | TP1/TP2 平均内移 → RR<1.5 打回率上升 |
| 无权重淘汰 + 每侧 3 条（修订） | 弱位（touches=1）占比升，总量 ≤6 兜底；最新点并入聚簇后无贴脸双线，锚定候选档位变少（第二档止盈需要前方 ≥2 条线，更常回退固定 RR） |

## 7. 边缘情况记录

1. **链式聚合**可产生总跨度 >merge_thr 的簇（A-B 0.4%、B-C 0.4% → 跨 0.8%）——维持链式（与现实现形状一致），测试钉死。
2. **每侧 5 条按时间截断**（非距现价）：前高/前低必含；离现价近但古老的老线会被截。
3. **破位后旧支撑线的触位误触发**：持住侧规则会翻侧放行，下游方向铁律兜底打回（代价一次 LLM 调用），暂不加侧向冲突过滤。
4. **kind/方向不一致怪癖**：向上突破旧支撑线时 breakout 信号 kind=support 但 direction=up——`_level_side` 既有语义，沿用。
5. **历史数据共存**：前端 optional 兼容、ai_analyzer/risk_guard/ai_agent 按 price 口径读、DB 无迁移。
6. **BTC 高档位精度**：100000×(1±0.003)=±300，双精度无损失；`Numeric(20,8)` 存 price 无截断。
