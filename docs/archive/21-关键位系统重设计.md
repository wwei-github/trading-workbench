# docs/21 关键位系统重设计（多源融合 + 角色状态机 + 回踩确认）

> 2026-09-27 设计。背景：正式网复盘确认「赚亏分界=入场位置」（docs/20），而现有
> 摆动点关键位是纯几何现算、无状态、无确认——假突破即时互换角色，AI 可能把刚
> 失效的支撑当回踩买点。本方案目标：**位置确认最准确**，不做最小改动。

## §1 现状与缺陷（为什么重做）

现状：`recent_swings()`（strategy/**init**.py）对 500 根 1h K线收盘价现算
order=3 摆动点 → AI 事实包 + P1 锚点解析（\_resolve_price）+ 前端图表标注。

四个结构性缺陷：

1. **无角色确认**：现价越过摆动点即换侧，假突破（插针收回）后该位立刻被当
   新角色使用——正是复盘里「位置差」亏损的来源之一
2. **单周期单源**：只有 1h 摆动点。4h 级别的大结构位（真正决定盈亏比的位）
   完全缺失；Donchian 轨、前日高低点等已被触发器验证有效的位不在锚点集合里
3. **无质量信息**：AI 看到的是 4 个裸价格（HH/LH/HL/LL 各 2 个），不知道哪个
   位被多次测试过、哪个是刚形成的一次性位——止损/止盈锚定质量全凭模型猜
4. **触发器与关键位脱钩**：T3 回踩确认只认 EMA21 一条线，回踩的是哪个结构位、
   破没破，触发器不关心

## §2 设计总览

```
┌─ 数据层 ─────────────────────────────────────────────┐
│ 候选位采集器 key_levels.py（纯函数，输入 K线集合）        │
│  ├ 1h 摆动点（order=3，收盘价口径，沿用现算法）           │
│  ├ 4h 摆动点（200 根，order=2 → 折算 1h 索引）          │
│  ├ Donchian 轨（20根窗口高/低，与 T1 同参）              │
│  ├ 前日高/低/收盘（日线界标，合约 24h 交易心理位）        │
│  └ 整数关口（价格量级的 1%/5% 圆位，可选项）              │
├─ 聚合层 ─────────────────────────────────────────────┐
│ 位合并：ATR 容差带内聚类（同带多源共振 → 强度加分）        │
├─ 状态层 ─────────────────────────────────────────────┐
│ 角色状态机：intact → broken → flipped_confirmed         │
│   （突破检测 → 回踩确认 → 失效降级），K线重放驱动          │
├─ 消费层 ─────────────────────────────────────────────┐
│ ① AI 事实包（结构化位表 + 状态 + 强度 + 距离）           │
│ ② P1 锚点解析（_resolve_price 改锚关键位表）             │
│ ③ T3 触发器（回踩确认对象从 EMA21 扩到已确认关键位）       │
│ ④ 前端图表（水平价位线 + 状态着色，替代裸 markers）       │
└──────────────────────────────────────────────────────┘
```

核心原则：**纯函数、无 DB 状态**。每次分析/扫描对现成 K 线重放状态机（500 根
1h + 200 根 4h 重放毫秒级），不建表不迁移；关键位是推导数据不是事实数据。

## §3 数据层：候选位采集（key_levels.collect_candidates）

新增 `backend/app/services/strategy/key_levels.py`：

```python
def collect_candidates(klines_1h, klines_4h) -> list[dict]
# 返回: [{"source": "swing_1h"|"swing_4h"|"donchian"|"prev_day",
#         "price": float, "idx_1h": int,           # 形成时刻（1h轴）
#         "kind": "high"|"low", "raw": {...}}]
```

- **swing_1h**：现 `find_swing_points(closes, closes, 3)` 原样迁入（收盘价口径
  保留——影线毛刺过滤是已验证的正确决策）
- **swing_4h**：4h 收盘价 `order=2`（4h 结构天然稀疏，order=3 确认延迟 12h+ 过
  长）；4h 索引×4 折算到 1h 轴。4h K线缺失时优雅降级（只出 1h 源）
- **donchian**：20 根窗口高/低（与 T1 `BREAKOUT_CHANNEL_BARS` 同参数），取窗口
  内极值时刻；每根推进滚动产生
- **prev_day**：UTC 日界切割 1h 序列，产出前一日 high/low/close 三价；前周高低
  在数据足够时同样产出
- **整数关口**（默认关，`KEY_LEVELS_PSYCHOLOGICAL=0`）：BTC 类大额币的 1000/
  500 整位，币价量级自适应步长；首次实现先关闭，避免噪音稀释共振

## §4 聚合层：ATR 容差带聚类（merge_levels）

```python
def merge_levels(candidates, atr_1h, tol_mult=0.5) -> list[Level]
# Level: {"price": float(带内加权均值), "sources": [...],
#         "touches": int, "first_idx": int, "last_idx": int,
#         "kind": "high"|"low"|"mixed"}
```

- 容差 = `ATR(14) × 0.5`（indicators.calc_atr 复用）：带内所有候选位合并为一个
  关键位，价格取**触及次数加权均值**（多次测试的位置会被市场「打磨」收敛，
  加权均值比简单均值更接近真实位）
- **共振强度 = sources 去重数 + min(rejections, 2)**：1h 摆动 + 4h 摆动 +
  Donchian 同时落在带内 → 强度 3；位上有影线拒绝史再加权（每次 +1，封顶 +2）。
  多周期同源共振是最强先验，拒绝是次强的单根证据
- `kind="mixed"`（带内既有高点又有低点）标记为「争夺位」，价格在位两侧反复穿
  越的位置——既有支撑测试又有压力测试，语义上比单向位更重要
- 触及定义：某根 K 线 high/low 进入 `price ± 0.25×ATR` 视为一次触及；连续触及
  合并为一次（防横盘刷次数），**touches 计数窗口排除位形成之前的 K 线**
- **拒绝事件（pin rejection，2026-09-27 补充）**：影线深入位价对侧（低点 <
  `price − 0.25×ATR` 或高点 > `price + 0.25×ATR`，即穿透触及带外沿）而该根
  收盘回到位价原侧 → 计一次拒绝。拒绝是「该位有真实防守」的最强单根证据
  （2B 法则的程序化检测），单独计 `rejections` 数并参与强度分；连续拒绝合并
  为一次，与触及共用窗口（防横盘刷数）。**触及与拒绝不重复计**：同一根K线
  只按更强语义（拒绝）计一次
- **组合拒绝（multi-bar rejection，2026-09-27 补充）**：拒绝不止单K影线形态——
  「单K收盘跌破位价、下一根快速收回」的双K组合（看涨吞没/刺透线/启明星落在
  位上）是同等强度的防守证据。判定：连续 ≤2 根内，位价对侧存在穿透（任一根
  low/high 进对侧 ≥0.25×ATR）且组合末根收盘收回原侧，同时组合内命中
  GOLDEN_12 对向形态（复用 candlestick.detect_all_patterns，`idx` 对准组合
  末根）→ 计一次拒绝。吞没/启明星检测自带实体门槛（≥近20根均实体）防小实体
  互包误报；组合拒绝与单K拒绝连续出现合并为一次

## §5 状态层：角色状态机（classify_levels）——本方案核心

对每个关键位，沿 1h K 线从形成时刻向后重放，赋予状态：

```
intact（有效）──收盘突破──▶ broken（刚突破，未确认）──回踩不破──▶ flipped_confirmed（翻转已确认）
    ▲                           │                                    │
    │                      再破突破方向极值                        收盘反向跌破原位
    └───────────────────────────┘                                    ▼
                                                        invalid（失效，仅保留展示）
```

- **突破判定**：收盘价越过位价 `± 0.1×ATR`（收盘口径，与摆动点同哲学——影线
  突破不算，杜绝插针假突破直接换角色）
- **回踩确认判定**（broken → flipped_confirmed）：突破后 ≤`confirm_window`
  （默认 12 根 1h）内，出现「回踩触及原位 ±0.25×ATR 且该根收盘回到突破侧」→
  确认；**组合确认**：回踩对侧若出现「穿透位价 + 次根收回」的金K组合（吞没/
  启明星等，判定同 §4 组合拒绝）同样构成确认——深度刺穿后的快速收回是比
  单K触碰更主动的确认。**这是用户指出的缺失环节：强势突破 → 回踩不破 →
  角色才正式翻转**
- **失效判定**：确认后收盘反向跌破原位 `±0.1×ATR`（假确认，翻转位被证伪）；
  或 broken 状态超窗未回踩（突破被抛弃，动能单边走远）
- 状态时效：`broken`/`flipped_confirmed` 都保留**突破方向**字段，翻转位的新角
  色由突破方向决定（向上突破的前阻力 → 翻转后是支撑）
- 重放窗口内同一位置可能多次突破/确认，**以最后一次事件为准**

每个 Level 输出完整状态字段：

```python
{"price", "sources", "touches", "rejections", "kind", "role": "support"|"resistance",
 "state": "intact"|"broken"|"flipped_confirmed"|"invalid",
 "flip_direction": 1|-1|None, "bars_since_event": int, "distance_pct": float}
```

`role` 按**当前现价**定（intact 位）或按 flip_direction 定（翻转位）——角色不再
是「现价在哪侧」的即时几何，而是有确认语义的角色。

## §6 消费层一：AI 事实包（结构化位表替代裸摆动点）

`recent_swings` 输出保留（图表标注仍用），事实包**新增**关键位块：

```
关键位（多源融合,ATR容差聚类,按距现价排序）:
  1. 0.4521 [支撑·翻转已确认] 强度4=共振3+拒绝1 触及5次·影线拒绝1次 距现价+0.8%
     ↑上破后12根内回踩确认（3根前）
  2. 0.4680 [压力·有效] 强度2=共振2 触及3次 距现价+2.1%
  3. 0.4470 [支撑·刚突破待确认] 强度1=共振1 距现价-0.5% ⚠未确认勿作回踩买点
```

格式要点：状态用中文直述；未确认翻转位显式标注「勿作回踩买点」——把上轮
分析发现的接飞刀风险在数据侧直接堵死；强度/触及次数给模型评位质量的依据。

## §7 消费层二：P1 锚点解析升级

`_resolve_price` 的 ref 枚举扩展（保持向后兼容）：

| ref（新增）                | 解析                                                                         |
| -------------------------- | ---------------------------------------------------------------------------- |
| `key_support_confirmed`    | 现价下方最近、state∈{intact(support侧), flipped_confirmed(向上翻转)} 的位    |
| `key_resistance_confirmed` | 现价上方最近、state∈{intact(resistance侧), flipped_confirmed(向下翻转)} 的位 |
| `key_nearest_strong`       | 距现价最近的强度≥2 位（不分角色，用于止盈锚）                                |

旧 ref（support/resistance/zone 系列）改为**从关键位表解析**而非裸摆动点：值不
变时行为兼容（位价本身就是摆动点加权），但自动获得状态过滤——`invalid` 位不再
被锚定。枚举名沿用 zone 时期命名的历史决策不变。

## §13 验证方案

- 单测（合成K线，阳阴列序按 docs/20 教训）：
  - 状态机：intact→broken→flipped_confirmed 全路径、确认超窗失效、假确认
    invalid、影线突破不触发（收盘口径）
  - 聚类：多源共振计数、加权均值、mixed 争夺位、touches 连续合并、
    **拒绝事件**（单K影线拒绝 + 双K组合拒绝/吞没·启明星落位、连续合并、
    与触及不重复计、强度加分封顶 +2）
  - 锚点：confirmed 过滤、invalid 排除、位表空回落
  - 触发器：翻转位回踩触发、EMA21 兜底不回归、0.25×ATR 边界
- 回放验证：用正式网已归因的「追高追空」亏损单，重放其入场时刻的关键位快照，
  人工核对新事实包是否把该入场标记为「未确认位勿买」——本方案有效性的
  直接证据
- 上线观察（1 周）：T3 触发分布（EMA21 vs 翻转位）、P0/P1 skip 率变化
  （提示词加严应使 skip 率小幅上升）、开单位置质量（入场距最近 confirmed 位
  的距离分布）

## §14 明确不做（防过度设计）

- 不落库关键位快照（推导数据可重算，存了反而要维护一致性）
- 不做斐波那契/成交量分布（Volume Profile）源——1h+4h+Donchian+日线已够，
  共振计数是强度的主要来源，再加源只增噪音
- 不动决策矩阵七行结构（docs/19）——触发器只换触碰数据源，矩阵语义不动
- 不做关键位预警推送——关键位是决策输入不是通知产品
