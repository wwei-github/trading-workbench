# docs/18 - K线图表开源插件调研

> 2026-10-09 · 背景：KlineChart 统一组件基于 **lightweight-charts v5.2**（TradingView 官方开源，Apache 2.0）。
> 经调研确认：iframe 嵌 TradingView 免费\_widget 无法绘制开单三线等业务标注（跨域无绘图 API）；
> Charting Library 官方明确**不向个人/爱好项目发放**（仅公司实体 + 公开站点）。
> 因此补齐 TV 观感的合法路径 = 为 lightweight-charts 挑选开源插件。本文为选型结论。

## 二、采用插件详评

### 2.1 lightweight-charts-drawing（画线主力）

- **内容**：86 工具 = 趋势线/射线/通道/平行通道、斐波那契回撤+扩展、江恩方/扇、艾略特波浪、
  形态（三角/旗形等）、矩形/圆/三角形、文本/标注/便签、表格、量能剖面（volume profile）、锚定 VWAP、
  测量工具、预测工具等（完整清单 docs/TOOLS.md）
- **交互复刻 TV**：点击放置、拖拽锚点/整体、磁吸（off/weak/strong）、Ctrl 多选与组拖、Ctrl 拖克隆、
  Shift 45° 约束、Escape 逐级退出、Delete 删除、图层 z-order（bringToFront/sendToBack）、
  按周期显隐（TV Visibility tab）
- **持久化**：`exportJSON()/importJSON()`，宿主自管存储 → 可做「画的支撑阻力线按 symbol 存后端，跨会话/跨设备保留」
- **架构优点**：Drawing 模型与 lwc 运行时分离（core 无 UI 无 lwc 依赖），JSON 导入有校验+迁移
- **风险**：极新（0.2.x，0.2 破坏 0.1 API），**锁精确版本**；未上 1.0 前升级需读 CHANGELOG
- **事件**：`change/add/update/remove/selection/tool/textEdit/tableEdit/gestureEnd`——textEdit/tableEdit 需宿主提供编辑 UI

### 2.2 lightweight-charts-indicators（指标层）

- **内容**：1290 指标 = 95 标准（MACD/RSI/布林/KDJ/ATR…）+ 1150 社区 + 45 K线形态；
  Pine v6 兼容口径（Wilder RSI、SMA 种子 EMA、总体标准差布林——与主流平台一致，这点对量化很重要）
- **渲染**：`IndicatorRenderer(chart, { paneIndex, mainSeries })` 管理副图窗格，`reuseSeries: true`
  支持增量更新（实时行情尾部追加不整段重设）；barcolor 不改数据只改 K 线颜色
- **依赖**：需同时装 `oakscriptjs`（Bar 类型）+ `lightweight-charts` peer
- **同作者**：与 drawing 同为 deepentropy 出品，API 风格一致，可放心组合
- **风险**：0.10.0 一天前刚发；1290 指标建议**按名显式 import**（tree-shaking），别全量注册

### 2.3 @tradingview/lwc-plugin-dual-range-histogram-series（官方）

- **内容**：基线上下双嵌套量柱，专为「买量/卖量」或「净流入」设计的紧凑叠加
- **价值**：比现有单色 volume 直方图信息量大——把 1h 成交按 taker 买/卖拆开（币安 aggTrades 可得），
  放量突破质量（量比维度）可视化升级
- **风险**：官方插件 20 天前发 1.0.0，Apache 2.0，风险最低；需要后端/前端补买卖量拆分数据源

## 三、暂缓/不采用理由

- **trendkit**：设计质量高（(time,price) 锚定、设备像素渲染、指标口径严谨），但 0.1.1 pre-release、
  功能被 drawing+indicators 组合覆盖。保留观察：若 drawing 的 86 工具过重，可换 trendkit 做轻量版（仅 5 工具）。
  其「设备像素网格渲染」「future bar 用 logical 索引投影」两点思路值得抄进自研代码。
- **brushable-area-series**：适合分段背景着色（如趋势期着色），当前需求没有，将来若做
  「4h 趋势期在 1h 图上着色带」可复用。
- **accessibility / hlc-area / stacked-\***：个人交易工具非刚需或场景不符。
- **watermark**：主库内置 `createTextWatermark(pane, {lines:[{text:'MAGICUSDT · 1h'}]})`，
  弹窗多图表叠放时增强辨识，零成本。

## 四、组合架构

```
KlineChart.tsx（现有，不推倒）
├─ CandlestickSeries + EMA 线 + 业务 priceLine（开多/止盈1/止盈2）   ← 现状保留
├─ SVG overlay 盈亏风险区                                            ← 现状保留
├─ SeriesMarkers（信号/成交标记）                                     ← 现状保留
├─ DrawingManager（lightweight-charts-drawing）                       ← 新增画线层
│    └─ exportJSON → localStorage（Phase 1）→ 后端 per symbol（Phase 2）
├─ IndicatorRenderer（lightweight-charts-indicators，按需 MACD/RSI）  ← 新增副图层
├─ DualRangeHistogram（买卖量，Phase 2 + 数据源改造）                  ← 新增量能层
└─ createTextWatermark(symbol·interval)                              ← 新增水印
```

**图层共存要点**（PoC 验证项）：

1. Drawing primitive 挂在 candle series 上，与 SVG overlay 的 z 序：SVG 在 canvas 之上，
   画线元素会被 SVG 遮挡——盈亏区是半透明填充（0.15/0.08 alpha），遮挡可接受；需实测
2. 画线模式下禁用图表拖拽平移冲突：DrawingManager 自带 placement 模式接管指针，TV 行为一致
3. 副图指标改变窗格高度 → SVG overlay 用 `priceToCoordinate` 每帧重算，需确认 pane 拆分后
   主图坐标换算仍正确（v5 pane API 变化）
4. 时间轴：KlineChart 有「固定时间位置」业务（交易复盘弹窗），画线锚定 (time,price) 不受影响

### 指标层换插件实施记录（2026-10-09）

- **indicators.ts 重写**：indicatorts + 手写渲染层 → lightweight-charts-indicators 目录驱动。
  每项 = `{calculate, renderable, legendNames?}`：calculate 调插件（Pine v6 口径，95 标准指标），
  renderable 输出 IndicatorRenderer 所需（overlay + plotConfig，插件模块经 `mod()` 适配——
  overlay 藏在 metadata、hline/fill 按需携带）；EMA/MA 多周期族 = 多次 calculate 合并 plots
  （plot0_0/1/2…）+ 合成 plotConfig。VOL 仍宿主直绘（up/down 着色 + volume 刻度插件不支持）
- **ChartCore 指标 effect**：旧「removeSeries + addSeries 手绘」→ 每指标一个 IndicatorRenderer
  （clear() 一次清全部 series/hline/primitives）；图例 series 引用取 `renderer.series()` 前 N 个
  （plotConfig 顺序），悬停联动保留；RSI 70/50/30 参考线由插件 hlineConfig 自带
- **周期切换渲染 bug**（candlePoints state 时序）：candlePoints 原为 state 在 data effect 里
  setState——切周期时先画新 K 线、指标 effect 晚一拍用旧数据，产生「新 K 线 + 旧指标」错位
  中间帧。改 useMemo 派生，series.setData 与指标重建同提交
- **切周期视口时间锚定**（TV 行为）：同实例换数据时先记 `getVisibleRange()`，新数据就位后
  clamp 恢复——切 1h↔4h 不再跳回「最近 130 根」；实例重建仍走缺省
- **重拉反馈**：切周期/更新拉取中右上角轻量 Spin（旧图保留不闪白）

### PoC + Phase 1 实施记录（2026-10-09）

ChartCore 集成（扫描/复盘两模式自动共享），tsc + vite build 通过：

- **图层共存**：DrawingManager 挂主 series（canvas primitive）；业务标注（AI 三线/复盘
  区域，SVG zIndex 10 + pointerEvents none）压画线之上，画线可正常点选拖动
- **工具栏**（18 工具四组）：几何 7（趋势线/水平线/水平射线/垂直线/矩形/平行通道/画笔）
  - 斐波·测量 3（回调/扩展/价格区间）+ 文本·标注 6（文本/便签/价格便签/气泡/箭头/表格）
  - 仓位预演 2（多单/空单，入场/止损/止盈框自带 RR 徽标）+ 磁吸三档（⌖ 关/弱吸K线/强吸开收高低）
  - 删除选中 + 清空
- **交互**（TV 对齐）：点击布防 → 放置 → 插件自动解除布防（'tool' 事件回同步 React 态）；
  Esc/再点取消；Delete 删除选中；放置流空文本提交即移除画线
- **文本族编辑器**：`textEdit`（pane 坐标）→ TextArea（Shift+Enter 换行），
  提交 `dm.update({...d, text})`；editorBusyRef 防 Enter+blur 双提交
- **表格编辑器**：`tableEdit`（单元格 box）→ Input + 行列操作条（+行/−行/+列/−列 →
  `dm.tableOp`）；单元格文本存于 `style.tableCells`（运行时确认）；操作按钮
  `onMouseDown preventDefault` 防 blur 先提交吞掉 click（blur-vs-click 竞态）
- **持久化**：`exportJSON → localStorage`，key=`kline-drawings:{chartKey}`（币种/交易
  分区），change 事件统一落盘；跨会话保留、跨周期有效（时间锚定）

**待线上验证**：SVG/primitive z 序在不同缩放下表现、布防时指针接管、副图 pane 存在时
文本坐标偏移。

## 七、自定义指标（2026-10-09 补充调研）

结论：**可以，三个层级**，按定制深度递增：

### 7.1 TS 手写计算（零新依赖，已在用）

KlineChart 的 EMA 线就是这个模式：JS/TS 里算出序列 → `chart.addSeries(LineSeries)` 画。
任何指标库里没有的自定义逻辑（如自研的 4h 趋势年龄着色带、量比标记）都走这条路，
`lightweight-charts-indicators` 的 readme 也官方演示了「库外自定义计算 + 手动画线」的集成写法。

### 7.2 直接跑 Pine 脚本：PineTS（pinets）

- **能力**：TypeScript 写的 **Pine Script v6/v5 运行时**——把 TradingView 原生 Pine 源码
  直接转译执行（lookback、`var` 持久化、`request.security()` 多周期、60+ ta 函数），
  输出 `plots` 纯 JS 数组，再喂给 lightweight-charts 画线
- **价值**：TradingView 社区 10 万+ 现成 Pine 指标可以拿来就跑，不用改写；
  自研策略的 Pine 原型也能搬到工作台
- **数据**：内置 Binance provider，也接受任意 OHLCV 数组（可喂本系统后端返回的 K线，口径与扫描端一致）
- **许可注意**：**AGPL-3.0-only**（LuxAlgo 出品，695★，5 天前发 0.11.0）。个人本地工具无碍；
  若将来公开 SaaS 化需开源集成代码——届时可换算到后端 Node 侧运行规避前端分发问题
- **依赖体积**：14.9 MB（含转译器），建议**动态 import 按需加载**，只在用户打开自定义指标面板时拉取

### 7.3 完全自定义视觉：v5 Custom Series / Primitives

`addCustomSeries(ICustomSeriesPaneView)` 定义全新序列类型（如 Heikin Ashi、自定义图表形态），
`attachPrimitive` 做 pane 级注记。极深定制才需要，当前无场景。

### 7.4 推荐组合

| 需求                                        | 路径                   |
| ------------------------------------------- | ---------------------- |
| 1290 库内指标                               | §2.2 indicators 直接用 |
| 自研逻辑（趋势年龄带、评分热区等）          | §7.1 TS 手写           |
| TradingView 社区 Pine 指标 / 自有 Pine 原型 | §7.2 PineTS 动态加载   |

> 三层共享同一份 K线数据源（后端 /klines），保证指标口径与扫描/复盘一致——
> 这是自建图表相对 iframe 嵌 TV 的根本优势，Pine 脚本喂自家数据即可复算验证。
