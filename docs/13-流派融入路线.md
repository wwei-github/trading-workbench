## 一、融入原则（先读）

1. **只融能被复盘体系验证的**——系统已有 24h 回放定论、补丁三态评估、预注册回放评估先例（docs/26 刺透/乌云 FAIL 即关）。任何新元素必须可被这条流水线证实或证伪，否则不进系统；
2. **不破坏「AI 提议、规则否决」权责结构**——新元素只有三种合法落位：闸门成员 / 投票成员 / AI 上下文输入。不允许出现绕过闸门的旁路；
3. **风格对立的坚决不融**——网格/做市/高频与本系统节拍和哲学冲突，宁缺毋滥；
4. **影子先行**——任何能打标的新元素先只做「加分/标注/日志」影子模式，复盘观察足够样本后再考虑升级为硬闸门。

## 二、第一梯队：高价值 × 低成本（7 项，建议近期实施）

### #1 BTC-beta 加权组合热度 ⭐ 优先 ✅ 已实施

- **来源流派**：组合管理（风险平价 / 相关性预算思想）
- **填补的真实漏洞**：加密山寨与 BTC 相关性普遍 0.7~0.9。现行热度闸门（钱包 × 20%）把 5 单同开视作 5 份独立风险，实际相当于同杠杆押一个 BTC 敞口——「单笔合规、组合隐性集中」；`same_direction_cap` 只数单数，不度量相关性。
- **方案**：热度闸门每单风险按 β 加权：`est_risk × β(币, BTC)`。β 用 1h K 线离线计算（近 30 天日收益对 BTC 回归），进程内缓存 24h；β 缺数据按 1.0（保守）。
- **接入点**：[trade_engine.py 热度闸门](../backend/app/services/trade_engine.py)（heat_used 求和处）+ 既有在跑单 risk_amount 首次入库时同时落 β 值。
- **成本**：低。纯计算改造，零新增交易所请求（1h K 线管道现成）。
- **预期效果**：作用在**尾部亏损的截断**而非日常盈亏——高相关同向单连环止损（一天 5 单全灭、日亏 -45% 基数级的场景）出现频率显著下降，日熔断（9% 阈值）被触发的次数减少；代价是牛市共振行情下单量变少（放弃部分同向重叠利润）。可观测指标：日熔断触发次数、单日最大回撤分布（预期尾部收窄）、同日止损单的相关性均值。日常胜率/单笔期望**不发生变化**——本项不改变选票，只改变组合风险形状。
- **验证**：影子跑 1 周（日志记录加权后 heat_used 与原值差），确认误拦率可接受后转正式。
- **状态（2026-10-04）：已实施**。热度闸门按 β 加权即日生效（`get_beta`：1h K 每 24 根采样 30 个日收益点对 BTC 回归，24h 进程缓存，缺失按 1.0；开单落 β 快照到 `trade_records.beta`）；与 docs/14 §1.4 口径调和——组合形状特征无单笔归因对象，不走影子等待期，靠**双口径日志**（β加权 + 原值同记）与「组合热度超限」拦截日志观察误拦率，1 周后复核。

### #2 周/月回撤分层熔断 ✅ 已实施

- **来源流派**：专业自营风控（equity curve trading / 分层风险预算）
- **填补的真实漏洞**：熔断只有 UTC 日维度（基数 × 9%）。连亏跨日的阴跌行情（日亏 5% 连续 4 天 = -18.5%）日级熔断天天复位天天开，缺少二级减速。
- **方案**：在日熔断之上加两层——周回撤（UTC 周一 0 点起已平仓净亏）≥ 15% 基数 → 本周剩余时间单笔预算减半；月回撤 ≥ 25% 基数 → 停开新仓 + 飞书推送人工复盘确认后恢复。阈值进 system_config 风控参数组（nullable + NULL 回落 env，复用 2026-10-02 模式）。
- **接入点**：`_daily_closed_pnl` 扩展为带时间窗参数；`try_open_for_analysis` 熔断闸门扩三段；`breaker_status_by_net` 卡片列同步展示三层。
- **成本**：极低。纯 DB 聚合，零新增请求。
- **预期效果**：把「连亏趋势日」的亏损上限从**单日 9% 基数**收紧为**周 ≤15%、月 ≤25%** 的阶梯包络（理论月最大亏损由无界的每日 9% 复利累积，变为 25% 封顶 + 周内减半减速）；月级熔断同时强制人工介入，打断「天天复位天天开」的钝性连亏循环。可观测指标：周/月回撤分布（预期 p95 显著下移）、连亏周发生率、月熔断后人工复盘次数。对盈利月份**零影响**（阈值只在亏损侧生效）。
- **验证**：参数可先按上述默认直上（这是风控收紧，不存在正向过拟合风险），跑 2 周复盘阈值松紧。
- **状态（2026-10-04）：已实施**。与方案的两点偏差：①「飞书推送」未做——月熔断恢复走**页面人工确认**（复盘页熔断卡片「确认复盘」按钮 → `POST /api/scans/config/monthly-breaker-ack` 写 `monthly_breaker_ack_at`；确认时刻在当前 UTC 月内 = 本月已复盘放行至月底，跨月自动重新武装），避免推送刷屏；②周减速实现为单笔预算 ×0.5（`_attempt_open` 内 `risk_scale`，fixed/pct 两模式同乘）。阈值 `weekly_dd_stop_pct`/`monthly_dd_stop_pct` 上页面（NULL 回落 env 15/25，0=关闭该层），熔断卡片三层优先级展示（月红 > 周橙 > 日红）。

### #3 CVD 第 8 票（订单流的免费子集）⬜ 未实施（待预注册回放）

- **来源流派**：订单流分析（Order Flow）——只取免费可算的累计成交量差
- **为什么可取**：币安 K 线自带 `takerBuyBaseVolume`（主动买量），CVD = 其累计差值。斜率（主动买压）与价格背离（价新高 CVD 不新高 = 真实需求不足）是订单流里唯一「零新增数据源、日线级 K 线即可算」的信号件。足迹/DOM 需要逐笔数据，成本高且 15m-1h 级别属杀鸡牛刀，明确不取。
- **方案**：`technical.py` 加 `analyze_cvd`（近 N 根 CVD 斜率 + 与价格背离判定，口径照 ADX/RSI 现有块风格），加入 7 指标多数决池。**多数决门槛同步 7→8 票、|net|≥3→≥4**（保持过半语义）。
- **接入点**：`technical.py` 新指标块 + `scanner.py` 投票聚合处门槛常量。
- **成本**：低。数据零成本，主要是回放调参（N 窗口、背离判定带）。
- **预期效果**：两类改善——① 拦掉「假突破」子集：价创高低点但主动买/卖压未跟随的突破（CVD 背离），这部分 historically 胜率偏低，第 8 票有独立否决力；② 震荡票面稀释度下降（票数 7→8 但门槛 |net|≥4，噪声票通过难度微升）。**效果上限受 CVD 与既有 OBV 票的相关性制约**（两者同源量能数据，信息增量可能只有 0.3-0.5 票 worth）——若回放显示与 OBV 高度共线（同票率 >80%），则改为替换 OBV 而非扩池。可观测指标：CVD 票的翻转胜率差（CVD 投反对票的单 vs 投赞成的单）、总体命中量变化（预期 -5%~-15%）、回放期期望 R 差。
- **验证**：**必须预注册回放**（docs/26 模式）——扩投票池改变全部信号流向，先回放证明 CVD 票加入后胜率/期望不劣化再上；影子期 CVD 仅入 votes_json 展示不计数。

### #4 OI 变化确认（衍生品四象限）⬜ 未实施（影子先行）

- **来源流派**：加密衍生品分析（价-OI 四象限）
- **语义**：价涨+OI 涨=新钱做多入场（趋势确认）；价涨+OI 跌=空头回补推动（不可持续）；价跌+OI 涨=新钱做空；价跌+OI 跌=多头去杠杆。现有 funding-extreme skill 已覆盖费率拥挤度，OI 是其另一半管道。
- **方案**：仅对 AI 配额前 10 候选拉 `/fapi/v1/openInterest`（每币 1 请求/轮，10 请求/轮可接受），当前值 vs 24h 前快照得 ΔOI；结果以「OI 确认/背离」标签注入 AI 上下文【市场环境】块 + quality_score ±3 修饰。**不进闸门硬规则**（OI 快照历史需积累，先影子）。
- **接入点**：`ai_analyzer.py` 上下文构建处（funding 注入点旁）；OI 24h 前快照可复用每小时扫描时顺手存 KV/内存环。
- **成本**：低。
- **预期效果**：主要是**给 AI 裁决层引入一个它现在看不到的维度**（当前上下文只有价/量/费率，无持仓结构）——预期效果分级：① 修饰 quality_score ±3：对配额排序产生边际影响，把「空头回补式上涨」（价涨 OI 跌）的候选排到队尾，这类单的历史特征是进场即失去动能；② AI 上下文标签：LLM 可据此在 borderline 案例改变 skip/suggest 判定，这是效果的主通道但不可精确预估，靠影子期分组统计验证。**明确预期边界**：OI 是慢变量（小时级），对 15m 触发时机的增益≈0；效果全部体现在「该不该做」而非「何时做」。
- **验证**：影子 ≥1 周，复盘按「OI 标签 × 开单结果」分组统计确认信息量后再决定是否升格。

### #5 ATR 跟进止损（Chandelier Exit）✅ 已实施

- **来源流派**：海龟/波动率出场体系
- **填补的真实漏洞**：TP2_HIT 与无 TP2 单的现行跟进止损仅基于摆动低点「只收紧」，趋势单回撤容忍度是静态的；波动放大时摆动低点跟不上，利润回吐比例不稳定。
- **方案**：跟进 SL = max(现 SL, 持仓期最高价 − k×ATR(22))（空单对称 min）。k 默认 3（海龟系标准），ATR 序列 `technical.py` 已实现（`atr_series` D1 口径现成）。**只收紧不放松的现行铁律保持不变**——ATR 值是候选，取与现 SL 更紧者。
- **接入点**：[trade_engine.py 跟进止损](../backend/app/services/trade_engine.py)（`_derive_exit_reason`/巡检 SL 管理段）。
- **成本**：低。
- **预期效果**：**TP2 后利润回吐比例收窄**——现行摆动低点跟进在急速趋势里摆动点跟不上价格，ATR 通道能贴住波动、波动放大时同步外扩（不被正常回踩扫出）、波动收缩时同步收紧（锁住更多利润）。机制上等价于把「从最高点回撤多少算趋势终结」从静态结构位变成波动自适应。可观测指标：TP2_HIT 单的「最高浮盈 → 实际出场」回吐 R 分布（预期均值收窄 0.2-0.4R）、被 ATR 腿提前扫出的单后续是否创新高（误杀率，k=3 下预期 <15%）。**下界有保证**：max(现SL, ATR) 的只收紧语义使最坏情况 = 恰好等于现状，不可能更差。
- **验证**：回放对比现行摆动跟进 vs ATR 跟进 vs max(两者) 的 R 分布；ATR 件逻辑简单，可直接上（有「只收紧」保底，最坏等于现状）。
- **状态（2026-10-04）：已实施**。`_chandelier_sl`：持仓期极值 = opened_at 起已收盘 1h K 极值（零 schema 改动），ATR 取 `atr_series(D1, 22)`；数据不可得返回 None 退化摆动腿（最坏 = 现状）。实现时补了一条铁律细节：**只收紧聚合必须包含现 SL**——ATR 腿可能松于现 SL（回调后高点回落），漏掉会把 SL 反向放松。k 上页面（`atr_trail_k`，NULL 回落 env 3，0=关闭 ATR 腿）。

### #6 时间止损（Time Stop）🚫 已回放，搁置不上（2026-10-05）

- **来源流派**：海龟法则
- **语义**：打止损与到止盈之外的第三种结果——**横着不动**。突破入场的前提是趋势延续，24h 不动 = 前提证伪；继续持仓只消耗在跑单名额（5 单上限）与组合热度。
- **方案**：巡检加一项：开仓满 24h 且未触发 TP1 且浮动盈亏 < 0.5R → 止损收紧至「成本 ± 往返费缓冲」（复用保本价口径，实际是小亏/保本出场），释放名额。24h/0.5R 为初值，回放后定。
- **接入点**：[trade_engine.py 巡检段](../backend/app/services/trade_engine.py)（TP1 保本移动逻辑旁，同一处 fee_rate 口径）。
- **成本**：低。
- **预期效果**：**名额周转率提升**——5 个在跑名额被横盘单占住时，后续 24h 内所有新信号全部被「满仓闸门」拦下（机会成本是隐性的、从不出现在盈亏表上）。时间止损把这部分死资本释放回信号池。量化预期：现行系统中「24h 未触发 TP1」单子占比约 30-40%（需回放实测），其中最终横到 expired/小亏出场的约一半——这部分每单提前 12-48h 释放名额。**对盈亏的直接改善接近零甚至略负**（砍掉极少数横盘后起飞的单），价值在期望不变的前提下提高资金/名额利用率。这正是必须先跑回放的原因：确认被砍单子的「后续起飞率」足够低。
- **验证**：**先跑历史回放**——统计现行系统中「24h 未触发 TP1」单子的最终 R 分布，确认时间止损确实改善期望（而非砍掉后续起飞的单）再上；这是全清单回放必要性最高的一项。
- **状态（2026-10-05）：已回放，搁置不上**（脚本 `backend/scripts/replay_time_stop.py` 入库可复跑）。预注册判定（docs/26 模式，跑数前拍板）：主指标 = 触发子集净改善 Σ(0−R_f) ≥ +2R 且起飞率（R_f≥1R 占比）<25% → 上；n<20 判样本不足。回放结果（线上 69 笔 CLOSED，09-29~10-04）：① 主参数（24h/0.5R）触发仅 **3 笔**（Δ=+2.3R 方向偏正但 n=3<20，样本不足不拍板）；② 15 组 W×R* 网格相邻参数从 +4.3R 翻到 −7.8R，**参数敏感无稳健区**；③ 结构性发现：**87%（60/69）的单 24h 内自行了结**——方案预估「24h 未触发 TP1」占 30-40%，实际本系统 15m 触发 + 30 分钟巡检 + 快止损结构下横盘占名额问题本身极小，时间止损可作用面很窄。**复核计划**：2-4 周后样本翻倍重跑，若主参数 Δ≥+2R、起飞率<25% 且网格不再翻转再走影子接入。

### #7 波动率状态机（Regime Filter）⬜ 未实施（影子折价起步）

- **来源流派**：宏观/CTA 体系（市场状态过滤）
- **语义**：突破策略在波动率收缩期假突破率最高（突破无后续燃料）；ATR 短窗/长窗比值（如 ATR14/ATR100 < 0.6）= 波动率压缩期，此时突破触发降权或跳过。
- **方案**：`scanner.py` 或触发器层加 ATR 比值计算；压缩期动作建议先只做 **quality_score 折价（影子）**，不直接拦触发。
- **成本**：低（ATR 现成）。
- **预期效果**：**突破假信号率下降**——波动率压缩期（ATR 短/长 <0.6）的突破缺乏后续燃料，历史形态是突破后 1-3 根内回落（假突破重灾区）。若压缩期占时间 25%、其突破胜率比扩张期低 10-15 个百分点（需影子实测），折价后这部分候选在配额排序中自然沉底。可观测指标：压缩期 vs 扩张期突破单的分组胜率/期望 R（影子期核心统计量）；两者差异不显著则本项无价值、直接关闭（这正是影子模式的意义——预期可能落空）。
- **验证**：影子统计「压缩期突破 vs 扩张期突破」的胜率差，有显著差再升格。

## 三、第二梯队：中等成本 × 高上限（回放验证后再上，5 项）

### #8 金字塔加仓（海龟 Units）⬜ 未实施（回放验证后再上）

- **语义**：趋势日收益上限的主要扩容器——浮盈达 0.5N×ATR 后按原预算 1/2 加仓、SL 整体上移，总敞口仍受热度闸门约束。
- **为什么放二档**：全清单**唯一需要动状态机核心**的项——TradeRecord 需加 ADD 事件类型、与「一分析一账号一单」复合唯一约束的语义冲突、熔断/热度/复盘归因口径都要跟着扩。改错了伤筋动骨。
- **前置条件**：先用历史数据回放证明「加仓腿」独立正期望，再动状态机。设计时加仓单建议**独立 TradeRecord 行**（parent_id 关联）而非同单扩仓，把对既有结算/复盘/统计的侵入压到最小。
- **预期效果**：**趋势日收益上限扩容**——现行单笔固定 1R 风险意味着单日大趋势的收益封顶在 2-3R/单；金字塔使强趋势单的风险敞口随盈利滚动放大（海龟体系的利润主要来源）。量化预期：回放中 TP2 达成率高的趋势日，单日收益分布右尾拉长（原 3R 封顶 → 加 2 次仓后理论 4-5R）；代价是回撤日加仓腿放大亏损约 10-20%（加仓腿本身带止损）。**净效果取决于趋势延续分布**——突破后延续 >2×ATR 的频率不足则净负。独立统计桶下对比「加仓腿 R 贡献」与「加仓腿止损损耗」即可裁决。

### #9 震荡市均值回归子系统 ⬜ 未实施（回放验证后再上）

- **语义**：4h ADX<20 门控已存在（现只用于 EMA 不投票），顺势扩成「震荡 regime → 布林触轨+RSI 极值反向单」，把全时段停摆的市场状态利用起来。
- **风险（最大）**：胜率高/盈亏比低的收益结构与趋势腿完全相反，会**污染复盘归因与补丁调参**（两种策略的同一标签含义相反）。
- **前置条件**：必须独立 RULE_VERSION 分组或独立统计桶；更稳妥的路径是先作为独立 tactic（10-战法模块）标注观察，积累样本后再决定是否立子系统。
- **预期效果**：**时间利用率**——震荡市约占全时段 40-50%（4h ADX<20 口径需实测），现行系统这段时间几乎零开单；均值回归单（布林触轨+RSI 极值反向）在震荡期胜率高（65-75% 典型值）但单笔盈亏比低（0.8-1.2）。**收益曲线形状将与趋势腿互补**：趋势月靠右尾、震荡月靠高胜率小赢——组合月度权益曲线更平滑。**反面效果必须正视**：混桶统计会污染补丁调参（同一「止损过宽」补丁对两种策略含义相反），且震荡期认错 regime（ADX 滞后）时反向单会撞上趋势启动 = 连环止损重灾区。独立分桶是硬前提，不是可选项。

### #10 流动性猎取确认档（SMC/ICT 可取子集）⬜ 未实施（回放验证后再上）

- **语义**：剔除订单块/FVG 等主观件后，ICT 唯一可工程化的硬核是 **sweep+reclaim**：插针击穿 swing 低点后收回 = 止损猎取完成，作为回踩 Stage-2 的更严确认档（在现触点体系上叠加，不替换）。
- **风险**：形态边界（插针深度/收回时限）极易过拟合。
- **前置条件**：照 docs/26 预注册回放模式，FAIL 即关（刺透/乌云先例）。
- **预期效果**：**回踩单的入场精度提升**——现行 Stage-2 确认只看触点成立，无法区分「回踩获支撑」与「下杀猎止损」；sweep+reclaim 档专杀后者（插针破位又收回 = 下方流动性已清空，趋势恢复概率更高的经典结构）。量化预期：仅对回踩触发的单子子集（占比需实测）提升胜率 3-8 个百分点，总单量下降（确认更严）。**诚实边界**：该形态在小级别上的噪声极大，若回放中 sweep 判定带的参数敏感度过高（±20% 参数使结论翻转），按 docs/26 惯例判 FAIL 关闭——形态类件过拟合是大概率事件，本项价值中位预期偏保守。

### #11 MACD 背驰修饰（缠论可取子集）⬜ 未实施（回放验证后再上）

- **语义**：缠论中唯一可量化移植的概念——价格新高而 MACD 峰值衰减 = 动量衰竭。作 exhaustion 修饰：入场信号伴随背驰 → quality_score 折价（影子起步）。
- **边界**：**不引入笔/中枢**——结构划定的主观性无法程序化拍板，强上即不可证伪。
- **预期效果**：**动量衰竭期的追高单折价**——突破信号若伴随背驰（价新高、MACD 峰衰减），意味着驱动这一浪的能量在衰减，此时期权价值最差的入场点；折价使这类单在配额竞争中让位给「动量扩张期」的突破。量化预期：背驰伴随的突破单占比约 10-20%（需实测），其历史胜率应比非背驰低（影子期验证这一前提本身）；若验证成立，折价可改善配额下候选的整体期望约 0.05-0.1R/单（边际但免费）。**边界明确**：折价不拦截——背驰后趋势仍可延续（强趋势中背驰钝化是常态），只做排序不做闸门。

### #12 再入场规则（海龟）⬜ 未实施（回放验证后再上）

- **语义**：止损出场但趋势结构未破坏（R²、EMA 排列、ADX 仍在）→ 允许一次低预算（1/2）再入场。现行 repeat_window 去重会拦掉此类再入场，需结构完好白名单豁免。
- **前置条件**：回放评估「止损后结构完好再入场」的独立胜率，正期望才开。
- **预期效果**：**大趋势的第二段参与权**——趋势行情中正常回踩扫掉首单止损后直接续走的场景（海龟体系再入场规则存在的理由），现行系统因 repeat_window 去重完全错过第二段。量化预期：止损单中「结构完好」占比约 30-40%（需实测），再入场腿独立胜率若 ≥ 首单的 80% 且预算减半，则对总期望贡献 +0.05-0.15R/趋势事件；代价是震荡市里「结构完好」判定滞后导致的二次止损损耗。**关键前置数据**：回放需回答「首单止损后 N 小时内同向续走的条件概率」——若 <40% 则本项净负，直接放弃。

## 四、明确不融入（负清单）

| 流派/元素             | 理由                                                                                      |
| --------------------- | ----------------------------------------------------------------------------------------- |
| 网格交易              | 震荡市策略，与趋势跟随方向性对立；本系统无震荡市开仓路径                                  |
| 做市 / 高频           | 每小时信号节拍 + 无限价腿（09-15 拍板）+ 半小时巡检，基础设施完全不匹配                   |
| 足迹/DOM 订单流       | 逐笔数据成本高；15m-1h 信号级别用足迹是杀鸡牛刀。CVD（#3）已取其免费精华                  |
| Token 解锁/事件日历   | 无可靠免费数据源，人工维护不可持续；唯一确定性事件（资金费 00/08/16 UTC）已有 skill 覆盖  |
| 端到端神经网络信号    | 违反「交易时段行为确定、可回放」架构底线（12 §八第 4 条）；LLM 已承担语义裁决且受闸门约束 |
| 江恩 / 波浪完整体系   | 主观计数无法程序化拍板，零可验证性                                                        |
| 完整 Wyckoff 结构标注 | 吸筹/派发示意图依赖主观画线；已取 OBV/量比两个可计算件，结构判定不取                      |
| 缠论笔/中枢           | 同上，结构划定主观性太强；仅背驰可移植（#11）                                             |

## 五、落地流程（复用现有基础设施）

```
预注册回放评估（docs/26 模式：先定成功标准与样本量，再跑历史）
   │ FAIL → 记录结论归档，不上（如 26 刺透/乌云先例）
   ▼ 通过
影子模式（真实行情只打标不决策；复盘按标签分组观察 ≥1 周）
   │ 标签信息量不足 → 降级或移除        ← 基础设施设计详见 [14-影子模式方案](14-影子模式方案.md)
   ▼ 有效
升格为闸门/投票成员（走补丁流程，system_config 参数 nullable 化）
   ▼
bump RULE_VERSION（复盘按版本分组隔离）
```

**优先级建议**：#2（周月熔断）与 #5（ATR 跟进）几乎零争议可直接做；#1（beta 热度）填补最真实漏洞、价值最高；#3（CVD）+ #4（OI）涉及投票池与配额链路，合并做一次预注册回放；#6（时间止损）回放必要性最高、先跑历史分布再定。
> （2026-10-05 执行记录：#2/#5 已实施、#1 已实施待 1 周双口径复核、#6 已回放判搁置。当前清单内下一步自然顺序 = #3+#4 合并预注册回放，或 #7 影子折价起步。）
