## 0. 当前 12 金K 判断逻辑快照（2026-09-30，代码事实）

三层架构：**形状判定**（candlestick.py 检测器）→ **证据裁决**（resolve_golden_evidence）→ **触发语境**（trigger.py 触点两段式）。任何一层不满足即不构成金K信号。

### 0.2 证据裁决（resolve_golden_evidence，复合确认 v2026-09-29-2）

wanted = 指标多数决方向，按序裁决：

1. **复合形态直通**：当根吞没/启明星/黄昏星方向匹配 → 直接确认（结构强，单根即够）
2. **双锤**：当根锤/流星方向匹配 → 须前根同形态才确认（单影线单根证据太弱，不确认）
3. **锤+趋势K**：当根无金K时，前根锤/流星（方向匹配）+ 当根顺向趋势K（实体 ≥75% 全长，与突破K线同口径）→ 组合确认，pattern 落前根形态

### 0.3 触发语境（触点两段式，docs/22）

- **纯金K已下线**（2026-09-29）：金K必须与触点配合，无触碰无 pending 的金K 一律不触发（正式网复盘纯金K 28 笔负期望）
- 触点体系（优先级）：retest 突破回测位 > swing 摆动结构位 > ema21 > ema55 > ema144；横向位影线可入带 ±0.3% 且收盘须守住；swing 只认 HL/LH（LL/HH 是接刀/追高不算回踩）；ema55/144 有数据门 + 排列门 + 斜率门三道门
- **当根确认**：当根触碰触点 + 当根金K → trigger_pullback_confirm
- **次根确认**：上根触碰（pending，锚点须恰为上一根K线开盘时间）+ 本根金K → 次根确认
- 触碰但无金K → 转 pending 待确认池（scanner 持久化；仅恰下一根有效，过期/方向反转即处置）
- reason 附量能注记 `·量比X(vs中位)·较前根×Y`（2026-09-30 §3.1，事实数据随信号落库）
- T1 突破（结构/趋势）优先级高于一切金K路径；pending 被强触发 supersede

## 3. 落地项（本次实施）

### 3.1 回踩金K 量能行（补「大量」要素，零风险信息增量）

`trigger.py` PULLBACK_CONFIRM 的 reason 注入量比，双口径对齐知识库：

```
…企稳且当根吞没确认·量比1.4（vs 20根中位）·较前根+30%
```

- `量比` = 信号K线量 ÷ 近 20 根中位量（程序唯一口径，突破路径同款）
- `较前根` = 信号K线量 vs 前一根（知识库口径「第二根量超前一根为加分项」）
- reason 随信号落库 → AI 事实包 / 前端 / 复盘快照全链路可见（量比为事实数据，AI 直接读 reason 原文，无需提示词声明）

### 3.2 提示词注入（❌ 已撤销，2026-09-30 二次拍板）

原方案四处注入：斐波那契次选锚（`_RULE_SL`）/ 形态质量语境（`_RULE_TOUCH`）/ 突破保守倾向（`render_signal_gate_block`）/ 观望纪律（`_RULE_DIRECTION`）。

**撤销原因**：用户拍板「提示词不要了，主要做对金K形态的判断，不满足要求的不判金K」——质量约束由 AI 自觉降权改为**程序硬门**（吞没影线门落地于 `candlestick.detect_engulfing`）。提示词只描述事实与已程序化门槛，不做劝导式纪律。四处已全部回退。
