## 四、待拍板：trail 模式的 RR 铁律（2026-10-10，个案 3 后续）

**矛盾**：trail 哲学 = 不设固定目标、让利润奔跑；现行 `risk_guard` 三价复算不看 tp_mode，trail 的 TP1 仅作参考价也须 ≥1.5R。BTWUSDT 21:55 实测：入场 ≈1.585 / 止损 1.5154（4.4%）/ 前高 1.660 → RR 1.09；1.5×ATR 延伸 ≈1.68 → 1.39；须 ≈2.1×ATR（1.69）才达标——**提示行给的三个目标在强趋势+宽止损盘面全部过不了铁律**，制度性堵死。

量化观点：固定目标 RR 是 ladder 语义的代理指标，拿来卡 trail 语义错位；宽止损风险已有独立闸门（max_stop_pct 硬上限 + 固定亏损法自动缩仓），不必靠 RR 兜底。

| 选项 | 内容 | 评价 |
|---|---|---|
| A 完全豁免 | tp_mode=trail 即不复算 RR | 实现最简；弱背景/震荡里的宽止损 trail 失去最后一道量化门 |
| **B 条件豁免（推荐）** | trail ∧ 4h phase ∈ {medium,strong,extreme} ∧ momentum=same → 豁免；否则仍 1.5R。资格复用取舍提示行判定（htf_phase 已落库，momentum 可补 stash） | 与提示行资格同源，弱背景仍受控；同步改 P0 `_RULE_TP_BASE`/P1 12/12.5/提示行/回炉反馈/测试 |
| C 降门槛 | trail 参考价 RR ≥1.0 | 本笔 1.09 险过，边界摩擦仍在 |
| D 维持 | 不改，接受此类单全部 skip | 与用户意图（trail 不看盈亏比）相悖 |

**拍板后须同步**：`risk_guard` 豁免逻辑 → P0/P1 提示词三处 → `render_indicator_block` 提示行措辞（豁免后「复算达标」改为「参考价如实上报趋势目标」）→ 回炉反馈消息 → 测试；程序判定变化 bump RULE_VERSION。

## 五、全链路审计结论（2026-10-10，含未修项）

### A 类：直接冲突

| # | 冲突 | 状态 |
|---|---|---|
| A0 | **trail RR 铁律语义错位**（§四） | 待拍板 |
| A1 | P1 rule 12「禁止跳档…应直接 skip」缺 trail 例外括注，与 12.5 取舍条款矛盾（P0 `_RULE_TP_BASE` 已有括注，P1 漏） | **未修**（P1 打开即踩） |
| A2 | 取舍提示行 × `skills/range-bound-fade`（「区间交易不追盈亏比直接 skip」）：1h 震荡可叠 4h medium+ 背景，两文本同现时冲突 | **未修**（提示行加 signal_type 条件即可） |
| A3 | 止损宽度纪律缺口：未配置上限时 AI 发明「4.4% 过宽」理由（21:55 实证）；三管线均无「不得以过宽为由 skip，宽止损由固定亏损法缩仓消化」显式纪律 | **未修** |

### B 类：语义漂移（双源不同步）

- **B4 金K白名单双源**：`SIGNAL_TYPE_LABELS` 手写清单 vs `candlestick.py` 白名单常量，10-09 的 12→8 靠手工同步；应常量化单一来源
- **B5** 旧类型标签残留（trigger_candlestick / trigger_pullback 标「仅历史数据」），占 token
- **B6 技能修复休眠**：SKILL.md 修订只影响 P1，P0 需显式双修（今日实际双修，但无机制保证）

### C 类：观测性缺口

- **C7** 4h phase/momentum/macro 结构字段不注入，靠 detail 字符串+提示行兜底（个案 2 实证字符串会被误读）
- **C8** 当前 tp_mode 配置（ai/ladder/trail）不注入，AI 选择可能被配置静默覆盖
- **C9** skip_reason 自由文本无编码，取舍路径使用率/保守 skip 率无法复盘统计

### D 类：防回归缺失

- **D10** 提示词不变量无测试断言（见 §六清单）
- **D11** 提示词变更无 checklist，今日模式 =「个案→补条款→发现新漏」

### 实施批次（建议）

1. **批次 1（止血）**：A1 + A2 + A3 + D10 不变量测试，一次提交
2. **批次 2（防漂移）**：B4 常量化 + B5 清理 + B6 维护约定，一次提交
3. **批次 3（观测）**：C7/C8 注入两行 + C9 skip 前缀编码，等批次 1 疗效数据后做

## 六、提示词不变量清单（改提示词前逐条过）

1. **跳档禁令必须带 trail 例外括注**：P0 `_RULE_TP_BASE` ↔ P1 rule 12 成对修改
2. **「动能同向」定义三处同步**：P0 `_TP_MODE_FIELD` ↔ P1 12.5 ↔ `technical.py` 注记措辞
3. **取舍资格条件单一来源**：提示行注入条件 ↔（拍板后）risk_guard 豁免条件必须同一组事实
4. **金K白名单以 `candlestick.py` 常量为唯一权威**（B4 落地前：改白名单必须手工同步 `SIGNAL_TYPE_LABELS`）
5. **止损宽度表述看配置状态**：`max_stop_pct` 配置时 gate block 注入「超限必弃单」；未配置时纪律面不得暗示有上限
6. **SKILL.md 与系统提示词冲突时**：以系统提示词为准修技能（今日 trend-pullback 先例）
7. **程序判定变化 bump RULE_VERSION**（`app/config.py`），复盘按版本分组隔离
8. **每次提示词改动**：P0、P1、技能、事实注入四个面逐一过（§三表格），确认无孤儿修改
