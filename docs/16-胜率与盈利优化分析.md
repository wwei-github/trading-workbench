# 第二部分 · 支撑分析

## §4 系统定位与真实盈利画像

**AI 增强的系统化短线趋势跟随/突破系统**——规则引擎持否决权与仓位权，LLM 做信号裁决与参数生成，固定比例风险模型定仓，三层风控闭环。权重结构：约 70% 在 7 指标多数决，25% 裸K/结构，量价仅加分。

```
扫描(7票多数决 + 触发器) → AI分析(建议分 + 程序复核) → 20+ 道开仓闸门
→ 市价开仓 + SL/TP → 半小时巡检 → 小时级复盘归因 → 补丁/版本演进
```

| 指标                | 数值                                                                                 | 来源                |
| ------------------- | ------------------------------------------------------------------------------------ | ------------------- |
| 正式网快照（74 笔） | 净 **-1.11U**、胜率 **26.6%**、PF **0.99**                                           | docs/06 历史演进    |
| **rec 60–69 段**    | 胜率 **12.5%**、avg **-0.659R**（16 笔）                                             | 项目记忆 2026-10-07 |
| **rec 70+ 段**      | 胜率 **41.4%**、avg **+0.324R**（29 笔）                                             | 同上                |
| 止损单结构          | **65% 亏损来自「曾浮盈→回撤全损」**（-16.4R）；TP1 中位 2.2R，保本机制**从未武装过** | docs/15 §一         |
| tp1_then_sl 泄漏    | 理论 +0.75R vs 实际 +0.04R，**每笔 0.7R 系统性泄漏**                                 | docs/06 §2.5        |

**结论：系统在盈亏平衡线上挣扎（PF≈1）。问题不是"没有策略"，而是三条具体漏损：** ① 评分门槛放行负期望段（→S-01）；② 0~2.2R 保护真空带、浮盈回撤全损（→S-02）；③ 执行层每笔 0.7R 泄漏（→P-09）。

**为什么不是"提高胜率"**：趋势突破系统胜率天然 ~40%，盲目提胜率会摧毁期望值——已被自身实验证明：B 腿把胜率 42%→60%，但期望 +0.054R→**-0.107R**（docs/15 §4.3，测试网 717 信号回放证伪）。全文按 EV + 尾部风险排序，任何"提胜率"建议必须先过 EV 检验。

## §7 纪律与负清单

**纪律**

- **任何改动必须在真实 TP1 分布（中位 2.2R）上验证**，别信小样本（现 42 笔、止损单 21 笔）。

- **旧账不翻**：跨 RULE_VERSION 成绩无证明力，按版本分组读数。
- **两网分层**：正式网为判定口径，测试网只作环境差异证据。

**负清单（明确"不要做"）**

- ❌ **不要为提高胜率而提前止盈**——B 腿已证伪（胜率↑但 EV 转负）。
- ❌ **不要在 P-06/P-07 落地前上 ML / 衍生品数据**（N-01/N-07 等）——没有回测与全量账本，无法区分 alpha 与过拟合。
- ❌ **不要在 decided 不足时动 A/B 腿**（S-02/S-03）——拿噪声当信号。
- ❌ **不要同时改多个变量**。
- ❌ **不要用跨 RULE_VERSION 的样本下结论**。
