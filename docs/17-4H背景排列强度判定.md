## 1. 为什么两度换轴

同日三版演进，每一版都在修上一版的误判洞：

| 版本 | 主轴 | 误判洞 |
| --- | --- | --- |
| 强/弱背景（09-24） | 间距（空间量）：≥1% 强 / <1% 弱 | 间距是波动率的函数，跨币语义不一；熊内反弹（两线都在 144 下）误标强多 |
| 趋势年龄（10-09 r2） | 交叉后根数（时间量）：前/中/后/衰竭 | 年龄量的是「趋势存在了多久」，不是「趋势有多强」——强度与年龄倒挂（见下） |
| **排列强度（10-10 五次拍板）** | **排列角度（发散度）** | —— |

年龄口径的倒挂实例：V 型急拉 18 根，排列已张开 ~1.9 ATR（证据很强），年龄却判「前期」不锁逆势；阴跌后横盘的老趋势，排列收窄到 0.4 ATR（证据已散），年龄却判「后期」把逆势锁得最死。**锁单矩阵真正想要的量是「趋势已被证明的程度」，排列角度才是直接度量**。且与 `gate_4h` / `structure_1h` 的发散度同一计算逻辑（|EMA差|/ATR），三处一把尺子，定标（docs/19 #15）可比。

## 2. 状态空间

基础状态不变（震荡 ADX(14)<20 / 均线纠缠 间距<0.1% / 多头 EMA21>EMA55 / 空头 EMA21<EMA55）× 宏观二值 × 动能修正 × **强度五档（主轴）**。

### 2.1 排列强度五档（主轴，2026-10-10）

```
div_min = min(|EMA21−EMA55|, |EMA55−EMA144|) / ATR(14, 4h)
```

- **双线取小者**：快线张开而慢线未张开不成强趋势（EMA55−144 不张 → 宏观未确认，趋势证词只算一半）。
- ATR 与 ema_gate 同口径（TR14 均值）；ATR 异常（≤0）→ `div_min=None` → 归 medium（排列有向但角度不可测，不给极端档也不误杀）。
- **0.5 阈值与 gate_4h 硬门线一致**：gate 线以下 = 排列未证明。

| phase | 判据（div_min） | 语义 |
| --- | --- | --- |
| weak 弱排列 | <0.5 | 排列未证明（gate 门线以下），锁单放行侧，质量分兜底 |
| medium 排列中等 | <1.0 | 趋势初证 |
| strong 排列强 | <2.0 | 趋势充分证明 |
| extreme 排列极强 | ≥2.0 | 过度张开，过热警惕均值回归（同向降档） |
| exhausted 衰竭期 | MACD 柱线翻向（凌驾于强度档） | 动能先于均线死亡，双向禁开新单 |

- **太新背离保护**：momentum=opposite 但 EMA21/55 交叉 ≤ `TREND_LAUNCH_MAX_BARS`(10) 根不判衰竭（V 型反弹柱线翻 1~10 根常见回拉），按强度档分档 + 「动能背离」注记。
- `age_bars` 降级为 detail 注记（「金叉刚发生·N根」「窗口内无交叉（极老趋势，按当前排列强度处理）」），不参与分档。
- 数值零保护沿用：单边匀速行情柱线渐近收敛，±1e-15 浮点尾数不误判翻向。
- detail 增注「排列角度{div_min:.2f}ATR」证据行（定标审计用）。

### 2.2 宏观守卫（EMA144，不变）

`macro_aligned = (EMA55 > EMA144) == (dir > 0)`——宏观确认的标志事件是 **EMA55 上穿/下穿 EMA144**。三线堆叠 6 种全枚举，行为收敛为二值：

| #   | 堆叠（降序） | macro_aligned | 注记                                        |
| --- | ------------ | ------------- | ------------------------------------------- |
| 1   | 21>55>144    | ✅            | 三线多头排列                                |
| 2   | 21>144>55    | ❌            | V型反转中期（EMA21已上穿144，EMA55未跟上）  |
| 3   | 144>21>55    | ❌            | 熊内反弹（144压制中·144斜率上行/走平/下行） |
| 4   | 55>21>144    | ✅            | 三线空头排列                                |
| 5   | 55>144>21    | ❌            | V型反转中期（EMA21已下穿144，EMA55未跟上）  |
| 6   | 144>55>21    | ❌            | 牛内回调（144托底中·斜率）                  |

设计原则不变：**144 的位置决定「能不能做」（二值行为），21 相对 144 的深浅决定「AI 怎么看」（注记语境）**。

### 2.3 动能修正器（MACD）

| momentum      | 判据                | 对强度档的影响                                     |
| ------------- | ------------------- | --------------------------------------------------- |
| aligned 同向  | 柱线符号与 dir 一致 | 无影响                                              |
| fading 衰减   | 符号同向但连续萎缩  | 仅注记（衰减不降档）                                |
| opposite 反向 | 符号与 dir 相反     | **衰竭判定（交叉 >10 根时）**；保护窗内按强度档+注记 |

MACD 金叉/死叉不进分档（与柱线共线、事件型时效差），进注记层。

## 3. 消费端行为

### 3.1 硬约束锁单矩阵（`enforce_htf_constraint`，五次拍板改排列强度口径）

| 档                       | 任何方向新单                                                    |
| ------------------------ | --------------------------------------------------------------- |
| 衰竭期（柱线已翻）       | **强制 skip**（双向禁开，矩阵最先判）+ 留痕（`htf_constraint`） |
| medium / strong / extreme ∧ 宏观同侧 | 顺势放行，**逆势强制 skip** + 留痕（`htf_constraint`） |
| weak（排列未证明）       | 放行                                                            |
| 逆宏观（任何档）         | 放行                                                            |

衰竭期双向禁开、逆宏观放行的理由沿袭 r2（§原 3.1）：动能已翻向时顺势单与逆势单都没有正期望依据，宁可错过；宏观确认以 EMA55 对 144 的穿越为准，单线收复不改二值行为。

### 3.2 质量分（五次拍板换档）

| 情形                     | 分值           |
| ------------------------ | -------------- |
| 同向：weak / medium / strong | +5 / +8 / +10 |
| 同向：extreme            | +6（过热降档：排列过度张开警惕均值回归） |
| 同向：衰竭期             | −6             |
| 逆向：weak / medium / strong / extreme | −6 / −10 / −12 / −8 |
| 逆向：衰竭期             | −4             |
| 逆宏观（叠加）           | −4             |

### 3.3 复盘维度「4h趋势期」（htf_phase 落库链路）

分析落库链路不变：`enforce_htf_constraint` stash `htf_phase`（suggest 且有 4h 数据时）→ `AIAnalysis.htf_phase` → 开单时 `_ai_snapshot` 随快照自持进 `trade_records` → `build_actual_review` 有序维度。**桶换五档**：弱排列 / 中等排列 / 强排列 / 极强排列 / 衰竭期 / 未知（旧行与无 4h 数据兜底）；**维度名保留「4h趋势期」**（前端列名与既有引用不动）。旧枚举行（launch/mid/late）标签缺失 → 未知。

分组验证目标：extreme 档（过热 +6）与 strong 档（+10）的胜率/EV 对照验证「过热降档」是否合理；衰竭期被双向禁开后理论上不再有新样本。
