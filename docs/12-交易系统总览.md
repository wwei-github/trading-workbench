## 一、系统定位与分类结论

**一句话定位**：AI 增强的系统化短线趋势跟随/突破交易系统——规则引擎掌握否决权与仓位权，LLM 负责信号裁决与参数生成，固定比例风险模型管理仓位，三层风控闭环。

### 1.1 全流派对照

主流交易方法论逐一对照代码实况，按采纳程度分四组（权重为信号影响的主观估计，供导航用；断言均已 grep 核实）：

**A. 主干采纳**

| 流派                                   | 地位                               | 权重     | 代码证据                                                                                                                                                   |
| -------------------------------------- | ---------------------------------- | -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **技术指标流**（Technical Indicators） | 决策核心：方向判定与信号过滤       | ~70%     | 7 指标多数决（MACD / 布林带 / RSI / SuperTrend / ADX±DI / OBV / EMA 排列，\|net\|≥3 才成候选）；R²+slope 趋势质量门；4h 背景由 ADX≥20 门控 EMA 排列        |
| **系统化趋势跟随**（道氏→海龟谱系）    | 策略哲学骨架：信号源与仓位模型同族 | 与上融合 | T1a Donchian 结构突破（海龟信号源同款）；波动率反比仓位（止损宽度定名义，海龟 N 系数仓位的固定亏损变体）；TP1 后跟进止损让利润奔跑；无均值回归/套利/做市腿 |

**B. 辅助采纳**

| 流派                                    | 地位                             | 权重     | 代码证据                                                                                                                                                                                               |
| --------------------------------------- | -------------------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **价格行为 / 裸K**                      | 辅助确认层：时机与结构锚定       | ~25%     | 12 金K 白名单（触发器之一，从不单独给信号）；突破实体比 ≥0.70 / 影线合计 ≤30%；摆动点（order=swing_order 局部极值，默认 3，触发层/事实包/标注同源，经典 swing high/low，**非缠论分型**——无包含处理）；SL 锚定结构位/ATR 轨道                     |
| **量价分析**（Wyckoff/VSA 谱系）        | 加分与确认：只排序不拦截         | ~4%      | 量比 ≥1.2 → quality_score +5（AI 配额排序，非门槛）；OBV 背离是 7 票之一（近 N 根净量占比量化）；**无 Wyckoff 结构判定**（无吸筹/派发示意、无 spring/upthrust、无成交量分布）——只取 OBV/量比两个指标件 |
| **动量交易**（Momentum）                | 趋势跟随的引擎面                 | 与上融合 | R²+slope 线性回归动量、SuperTrend ATR 通道跟踪、放量确认；追高上限 1.5% 即动量策略「不接最后一棒」的工程化                                                                                             |
| **衍生品情绪/拥挤度**（资金费率+OI）    | AI 裁决层输入之一（加密特有）    | ~1%      | AI 上下文【市场环境】块注入本币资金费率 + BTC 状态（docs/24 A4①）；`skills/funding-extreme-handling`：\|费率\|>0.1% 拥挤方向逆向处理、OI 同升提示拥挤；仅影响 LLM 裁决，不进闸门硬规则                 |
| **均值回归**（Mean Reversion）          | 仅以投票票面稀释参与，无独立策略 | ε        | RSI 超买超卖、布林触轨、OBV 背离本质是逆势逻辑——但只占 7 票少数，被 \|net\|≥3 多数决稀释；系统无震荡市开仓路径                                                                                         |
| **斐波那契/谐波**（Fibonacci/Harmonic） | 开关预留、未实施                 | 0        | `fib_enabled` 列+接口全链预留（默认 False，标注二期），strategy/ 无任何 fib 计算实现；谐波形态（Gartley/Bat 等）无                                                                                     |

**C. 明确未采纳**（理念可相容、代码零实现）

| 流派                                             | 搜证结论                                                                           |
| ------------------------------------------------ | ---------------------------------------------------------------------------------- |
| **缠论**                                         | 无分型/笔/线段/中枢/背驰/区间套概念；swing 用经典局部极值而非包含处理              |
| **波浪理论**（Elliott Wave）                     | 无浪型计数；fib 未实施故无黄金分割驱动逻辑                                         |
| **江恩理论**（Gann）                             | 无角度线/时间周期/价格时间方形                                                     |
| **SMC / ICT**（智能钱、订单块、流动性猎取、FVG） | 无 order block / liquidity / fair value gap 判定                                   |
| **订单流**（Order Flow / 足迹 / DOM）            | 无逐笔足迹分析；唯一「走订单簿」代码是开仓滑点实测（执行层技术，非订单流分析流派） |
| **市场轮廓 / Volume Profile**                    | 无 TPO/POC/成交分布剖面                                                            |

**D. 风格对立或场景排除**（主动排除，非「未实现」）

| 流派                    | 排除理由                                                                          |
| ----------------------- | --------------------------------------------------------------------------------- |
| **统计套利 / 因子模型** | 无协整配对、无多因子截面模型；复盘补丁是人工审核的规则修正，非统计学习            |
| **做市 / 高频**         | 每小时一轮信号、半小时巡检、小时级持仓天然排除；无限价腿（09-15 拍板回退）        |
| **网格交易**            | 震荡市策略，与趋势跟随方向性对立；代码中「grid」仅指价格 tick 取整网格            |
| **基本面 / 链上宏观**   | 币种无财报概念；链上数据（TVL/交易所净流等）未接入，AI 上下文仅行情+指标+资金费率 |

```
采纳谱系树：
系统化趋势跟随（道氏/海龟哲学）———— 骨架：信号源 + 波动率仓位 + 跟进止损
  └─ 技术指标流 ~70% ———— 方向（7 票多数决）+ 过滤（R²/ADX）
       ├─ 价格行为/裸K ~25% —— 时机（金K/实体质量门）+ 结构锚定（swing/SL）
       ├─ 量价 ~4% ————————— 排序加分（量比/OBV 背离），永不拦截
       └─ 衍生品情绪 ~1% ———— AI 上下文（资金费率/OI 拥挤度）
  （均值回归仅以稀释票面存在；缠论/波浪/江恩/SMC/订单流/VPA 结构 = 0；
    统计套利/做市/高频/网格/基本面 = 主动排除）
```

**最接近的同类**：海龟交易法则（Donchian 突破 + 波动率仓位）的现代 AI 增强变体——信号源同源（结构/趋势突破），仓位模型同族（波动率反比/固定比例），增强点在 AI 裁决层与闸门工程。

### 1.2 分类学定位（按七个维度）

| 维度       | 分类                                                | 依据                                                                                                         |
| ---------- | --------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| 策略风格   | **趋势跟随 + 突破入场**（Trend-Following Breakout） | T1a 结构突破（Donchian 轨）/ T1b 趋势突破 / 回踩两段式确认入场；顺趋势方向开仓，无均值回归、无套利、无做市腿 |
| 持仓周期   | **短线波段**（intraday ~ swing）                    | 15m/1h 级信号，持仓数小时至 1-2 天；24h 回放定论胜负                                                         |
| 决策架构   | **规则 + AI 混合**（AI 提议、规则否决）             | LLM 产出决策与三价参数；程序复核 + 20 余道硬闸门持否决权；AI 无绕过闸门的能力                                |
| 仓位模型   | **固定比例风险**（Fixed Fractional Risk）           | 单笔风险 = 风险基数 × 3%（或固定金额），止损宽度反比定名义，杠杆只调保证金效率不改风险额                     |
| 风控架构   | **三层闭环**（事前闸门 / 事中管理 / 事后进化）      | 开仓前 20+ 道闸门；持仓中保本移损+跟进止损+分批止盈；盘后熔断+黑名单+复盘补丁                                |
| 市场与方向 | 加密 USDT-M 永续合约，**多空双向**，双网灰度        | 测试网（默认开）+ 正式网（默认关）镜像跟单                                                                   |
| 执行方式   | 市价入场 + 条件单管理                               | 市价开仓，STOP_MARKET/TAKE_PROFIT_MARKET 挂单，无限价腿（09-15 拍板回退）                                    |

### 1.3 相邻分类辨析

- 不是**黑箱 AI 交易**——AI 输出只是「一份待复核的提案」，任何数值都过程序复算（RR 铁律、三价一致性、仓位复算），风控不依赖 LLM 的自觉；
- 不是**高频/日内刷单**——每小时一轮信号、半小时巡检的节拍，持仓以小时计；
- 不是**全自主机器学习系统**——无在线训练、无因子挖掘；「学习」发生在盘后复盘补丁层（人审核后 bump RULE_VERSION），交易时段策略行为完全确定。

## 二、交易逻辑全景链

```
【每小时 · 第2分钟】扫描（01）
  A 宇宙层：24h 成交额 ≥ 300 万 USDT + 新币冷静期 14 天 + repeat 窗口去重
  C 层：下单环境上架校验（双网并集）+ 交易所风险档位
  D 层：黑名单过滤（手动永久 / 止损超预算自动冷却 14 天 / ≥1.8R 永久）
        ↓
  触发器判定（02）：T1a 结构突破 / T1b 趋势突破 / 回踩两段式 + 金K 白名单
        ↓
  7 指标多数决（|net| ≥ 3）→ quality_score 0-100 排序 → 取前 ai_max_per_scan=10
        ↓
【每小时 · 扫描后即时】AI 分析（03）
  上下文：K线 + 指标 + 4h HTF 背景 + 战法剧本（仅借鉴标注）
  输出契约：suggest/skip、方向、entry/SL/TP1/TP2、RR、position_pct、评分 0-100（tp_mode/entry_strategy/strategy2_* 四字段 2026-10-12 退役，历史列保留）
  程序复核（risk_guard）：RR ≥ 1.5 铁律、三价一致性、仓位复算
  双评委辩论复核 → 强制 skip 则终止
        ↓
【分析完成后即时】开仓执行（04）
  try_open 闸门链（账号扇出 → 评分门槛+连损降速 → 单数上限
  → 余额风控 → 组合热度 → 同向上限 → 当日熔断）
  _attempt_open 闸门链（同币无仓 → 黑名单 → 上架 → 入场偏离 ≤1% → 可挂性
  → RR 现价复算 → 强平闸门+动态杠杆 → 最小规则 → 保证金 → 滑点实测 ≤0.3%
  → 价差预检 → TP 分批预检）
        ↓
  市价开仓 → 逐仓挂 SL（STOP_MARKET·标记价触发·全平）+ TP1/TP2（TAKE_PROFIT_MARKET·成交价触发·分批减仓）；出场恒为 ladder（trail 纯跟踪 2026-10-12 退役）
        ↓
【每半小时】巡检管理（04）
  结算平仓单（realized 含手续费/资金费）→ TP/SL 事件推进 → TP1 后止损移保本
  （成本 ± 往返费缓冲）→ 跟进止损（只收紧）→ AI 持仓诊断 → 自动导入 App 手动仓
        ↓
【每小时 · 第14分】复盘归因（06）
  24h 回放定论（win_tp1/win_tp2/loss/expired）→ LLM 错误归因 → 标签热度
  → 补丁三态评估（每日 11:45）→ 人工审核 → RULE_VERSION bump
```

现货屯币（07）是**独立旁路**：日检/定投/周研判，底仓 ≥70% 不卖，与合约系统零共享。

## 三、仓位管理体系（核心）

### 3.1 单笔风险预算（固定亏损法）

```
风险基数 = 钱包首位取整，夹在 [100, 5000]
          （4800→4000，980→900，65→100，5200/15000→5000）
          —— trade_engine._capital_base

单笔风险预算 = 基数 × risk_pct%（默认 3%，页面可调 0.1~20）
             或 fixed 模式固定 USDT 金额（默认 3）
          —— risk_budget.resolve_risk_budget

近锚折价：止损锚点贴近现价（近锚单）时预算 × 0.7
          （near_anchor_factor，近锚单胜率统计偏低）
```

### 3.2 仓位推导（波动率反比）

```
名义仓位 notional = 风险预算 ÷ 止损宽度 stop_pct
数量 qty = notional ÷ 现价（按交易所 filters 取整，超单笔上限则缩减）

含义：止损越宽 → 仓位越小；止损越窄 → 仓位越大。
无论止损宽窄，打止损时亏损恒等于风险预算（固定亏损法）。
```

### 3.3 杠杆：只管保证金效率，不管风险

```
动态杠杆 = 从上限（默认 20×，页面可调）向下搜索，
          首个「强平距离 > 止损距离」的杠杆；下限 8×
          —— _adaptive_leverage，逐仓隔离
杠杆取三者最小：配置上限 / 该名义档位最大杠杆 / 精确档 MMR 强平安全杠杆

固定亏损法下止损亏损 = 名义 × stop_pct，与杠杆无关；
杠杆只决定保证金占用（名义/杠杆）与强平距离（≈1/杠杆 − MMR）。
止损距离超 8× 下限的强平闸门 → 直接放弃（BATUSDT 案例）。
```

### 3.4 组合层预算

```
在跑单上限：max_open_trades=5（TP1_HIT/TP2_HIT 已锁险单不占名额）
组合热度：在跑单止损合计 + 本单预估 > 钱包 × 20% → 拦截（防单笔合规、组合超载）
同向上限：same_direction_cap（防趋势同震时同向连损）
最低可用余额：可用 < 钱包 × 50% → 停开（trading_min_free_pct）
```

## 四、订单执行与持仓管理

### 4.1 订单结构

| 单           | 类型                            | 触发基准                      | 语义                                               |
| ------------ | ------------------------------- | ----------------------------- | -------------------------------------------------- |
| 入场         | MARKET 市价                     | —                             | 入场偏离 ≤1% 才市价；待回踩单回踩进容差内市价入场  |
| 止损 SL      | STOP_MARKET + closePosition     | **标记价格** MARK_PRICE       | 触发即市价全平；标记价防插针误触发、与强平引擎对齐 |
| 止盈 TP1/TP2 | TAKE_PROFIT_MARKET + reduceOnly | **最新成交价** CONTRACT_PRICE | 分批减仓（qty_tp1/qty_tp2），先落袋后让利润奔跑（出场恒 ladder；trail 无档位模式已随策略二退役，2026-10-12） |

### 4.2 持仓状态机

```
ladder：OPENED → TP1_HIT（TP1 成交：止损移保本 = 成本价 ± 往返费缓冲，只收紧、幂等）
        → TP2_HIT（仅剩跟进仓，SL 以 TP1 价夹紧保本锚定）
        → CLOSED（exit_reason：sl / tp1_then_sl / tp1_trail / trail_sl /
                  breakeven_sl / manual / error）
（trail 纯跟踪分支已随策略二退役，2026-10-12 删除——历史存量 trail 单失去
  巡检，仅剩交易所 SL 兜底；exit_reason 的 tp1_trail/trail_sl 等标签保留以
  正确归因存量单）
FAILED：仅 -1121 未上架落 FAILED 记录（等下次信号重试）
```

要点：

- **TP1 后盈亏比结构质变**：止损已在成本上方，剩余仓是「零风险敞口 + 跟进空间」——这也是在跑单上限给 TP1_HIT/TP2_HIT 让名额的原因；
- 无 TP2 的单 TP1 后启用**跟进止损**（只收紧不放松）；
- 保本价外推一个往返 taker 费缓冲（0.05%×2）——纯成本价保本实际仍亏手续费（docs/24 A1''）；
- **止盈模式（2026-10-12 更新）**：出场恒为 ladder（TP1/TP2 分批挂单）；`tp_mode` 三态与 trail 专属腿（1×ATR 武装保本 / EMA21 减半 / 浮盈落袋，2026-10-10~10-12 期功能）随策略二删除，字段仅作历史透出（旧行 tp_mode=trail 不再有特殊处理）。

### 4.3 结算与对账

- 每半小时巡检结算：realized_pnl 按交易所 income 口径，**含手续费与资金费**；
- 划转流水逐账号同步（TRANSFER）；
- `trade_recon` 泄漏对账：理论 R（tp1 占比 × RR1，余档保本 0）对照实际 R，量化滑点/费用/执行偏差的总泄漏。

- 当日熔断只停开仓，AI 分析/巡检/复盘照常；

## 八、设计哲学（为什么是现在这个形状）

1. **风险额先于仓位**——先定「这单最多亏多少」（基数×3%），再由止损宽度反推仓位大小；仓位是风险的**结果**而不是输入。这使系统在任何止损宽度、任何币种上保持一致的破产风险速率。
2. **AI 有建议权、规则有否决权**——LLM 负责最难的「这笔值不值得做」的语义判断（形态、背景、战法），一切数值越过程序复算线即作废；风控闸门链对 AI 与手动单一视同仁。
3. **时机的代价用闸门买**——市价入场注定牺牲价格质量，系统用滑点实测/价差预检/入场偏离容差三道闸把「买贵」限制在预算内；出场端因时点不可选（止损触发=砸盘时刻），用标记价触发+冷静期过滤薄盘币兜底。
4. **进化在盘后**——交易时段行为确定（可回放、可对账），策略改进走「复盘归因 → 补丁评估 → 人工审核 → 版本 bump」的受控通道，杜绝在线学习引入的不可解释性。
5. **双网灰度、实盘默认关**——一切新策略行为先在测试网验证，正式网是显式开启的选择；镜像单机制让同一次决策在两网获得天然 A/B 对照。
6. **层级化确认，权重递减**——指标定方向（7 票多数决）、K 线定时机（金K 白名单）、量能做加分（+5 排序）、结构位定止损（swing 锚定）。任何单一流派元素都不单独持有决策权：金K 形态再标准，过不了指标多数决就是废票；OBV 背离再明显，也只有七分之一票。层级化让单一方法论的失效模式（指标在震荡市钝化、裸K 在高波动市失真）被其余层的独立逻辑对冲，而不是系统性放大。
