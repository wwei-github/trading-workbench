# 26 - 刺透线/乌云盖顶白名单回归 · 历史回放评估方案

> **性质**：落地 docs/25 §4 挂起项「刺透线/乌云盖顶白名单回归」的评估路径。A5b 实盘分组报表攒 ≥30 笔边际样本需数周，先用历史 1h K 线做全管线假想回放，预注册判定规则，数据正期望才进入实施。
> **拍板（2026-10-01）**：执行回放评估；实施与否由回放数据裁决（预注册规则见 §5）。
> **结论（同日）**：全量回放判定 **FAIL**（Wilson LB 32.2% < 40% 盈亏平衡、净期望 −0.13R），白名单回归按预注册纪律**关闭**，结果记录见 §8。

## 1. 待验假设

**H1**：把刺透线（`piercing_line`，看涨）/乌云盖顶（`dark_cloud_cover`，看跌）作为复合直通证据加入金K白名单后，**新增（边际）回踩确认信号**的假想期望为正。

辅助事实（已由代码构造保证）：

- 刺透与看涨吞没**互斥**（检测器要求 `c2 < o1`，吞没要求收盘越过前开盘价）——边际归因干净，不存在"同一根K线两种形态抢功"。
- 2026-09-12 移出白名单理由是"信号质量弱或与保留形态高度重叠"——互斥构造已排除重叠，剩下只验证"弱"。

## 2. 回放管线（完全复用生产函数，口径零分叉）

调用生产入口 `scanner.detect_indicator_candidate(pool, symbol, klines, pending, flt, retest=None, event_out)`，仅 `pool`（4h 数据源）与 `GOLDEN_12`（白名单）两处打桩：

| 环节     | 复用                                                             | 说明                                                                                                       |
| -------- | ---------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| 数据     | Binance fapi `/fapi/v1/klines`                                   | 1h `WINDOW=240` 根滑动窗（= 扫描 `kline_window` 默认）+ 4h 按信号时刻切片                                  |
| 方向     | `compute_indicator_votes`                                        | 6 票预筛 → 4h 第 7 票，\|net\|≥3 且 voted≥5，生产同款                                                      |
| 4h 门    | `analyze_htf_background`                                         | ranging 过滤 + 方向一致性门（htf 切片 = 开盘时间 < 信号K线收盘时刻，内部剔未收盘根，与生产同时刻语义一致） |
| 触发     | `detect_trigger`                                                 | 触点两段式决策矩阵全量保留                                                                                 |
| 白名单   | 打桩 `candlestick.GOLDEN_12 ∪ {piercing_line, dark_cloud_cover}` | 刺透/乌云不在 `SINGLE_SHADOW_PATTERNS` → 走复合直通（规则1），与吞没/启明星同路径                          |
| pending  | 链式模拟                                                         | `upsert` op 即快照（direction/touch_ref/stage1_candle_open），逐步传递；终态/替换即清                      |
| 回放定论 | `review_tasks.replay_suggestion`                                 | 先触止损→loss（同根歧义保守 loss）；触 tp1 后触损→win_tp1                                                  |

**刻意关闭（口径差异声明）**：`retest` 破轨事件不重建（触点少一类）、无重复窗口去重。两运行组（基线/变体）同等受限，边际对比不失真；样本偏保守。

## 3. 三价规则（无 AI 参与的程序化假想单）

生产三价由 AI 给出，回放用程序规则替代（与 AI 止损纪律同构、固定 RR 便于跨形态对比）：

- **入场** = 信号K线收盘价（生产扫描在收盘后数分钟内进行，现价 ≈ 信号收盘价）
- **止损** = 近锚：做多 `min(最近5根low) × (1−0.3%)`，做空镜像（A5b 报表的 near 锚口径）
- **止盈一** = 入场 ± 1.5×止损距离（`AI_RR_MIN=1.5` 铁律下限，tp2=0 单目标）
- **观察窗** = 后 240 根（10 天）；未定论 outcome=open（不计入主口径，单列）

**敏感性**：费率净期望 = R − `FEE_RT/(止损距离/入场)`，`FEE_RT=0.14%`（taker 0.05%×2 + 滑点 0.02%×2）。

## 4. 变体与分组

- **baseline**：现行 `GOLDEN_12`（6 形态）跑全量历史
- **variant**：白名单扩展后跑同一历史
- **marginal_raw** = variant 信号 − baseline 信号（键 = 币种+信号K线开盘时间）
- **marginal_gated** = marginal_raw 中**决断K线总影线 ≤ 全长 40%** 的子集（与吞没/启明星 `DECISION_SHADOW_MAX_PCT=0.40` 同口径——若未来实施，检测器须带同款质量门；主判定用 gated，raw 仅敏感性）

## 5. 判定规则（预注册，防 p-hacking）

对 **marginal_gated**（可按形态/方向细分）：

| #   | 规则                 | 阈值                                       |
| --- | -------------------- | ------------------------------------------ |
| 1   | 样本量               | ≥ 30 笔（docs/24 观察期纪律同款）          |
| 2   | 胜率 Wilson 95% 下界 | > 盈亏平衡胜率 1/(1+1.5) = 40%             |
| 3   | 毛期望               | > 0 R                                      |
| 4   | 净费率期望           | > 0 R                                      |
| 5   | 集中度               | 单币种占比 < 40%（防单一行情贡献全部样本） |

**两阶段验收**：回放通过 → 实施白名单回归（检测器加 40% 决断影线门 + bump RULE_VERSION）→ 实盘 A5b 报表攒 ≥30 笔边际单复核正期望后才视为终验。回放任一规则不满足 → 挂起项正式关闭（记入 docs/25 §4）。

## 6. 已知偏差（结论解读时须考虑）

- **幸存者偏差**：宇宙取当前 24h 成交额 top N（≥`MIN_VOLUME_24H`），已下架币不在样本——形态层评估可接受。
- **无资金费率/强平模拟**：10 天观察窗内影响小。
- **固定 1.5R 止盈**：非结构锚止盈，实际 AI 止盈分布不同——回放只回答"形态证据是否带来正期望边际"，不预测实盘 RR 分布。
- **假想回放 ≠ 实盘**：见 docs/24 修订 v2——历史混合成绩不具参考性，本回放是**新假设的探索性证据**，终验仍以实盘 A5b 为准。

**结论**：H1 否证——在近锚止损 + 固定 1.5R 止盈口径下，刺透/乌云盖顶的边际回踩确认信号毛期望仅贴平零、不足以覆盖往返 0.14% 费率。按预注册纪律，白名单回归**关闭**（docs/25 §4 已记）。

**探索性细分（不构成实施依据，防多重比较）**：

- 按触点：swing 84 笔胜率 50%（Wilson LB ≈40.5%，贴线）vs ema21 58 笔 26%（主要拖累）；ema55 样本 3 笔无意义。
- 按形态：piercing_line 98 笔 41% vs dark_cloud_cover 47 笔 38%，方向 1/−1 同形同值。
- 若未来重启，唯一合理路径 = 以「仅 swing 触点的刺透线」为**新假设**重新走一遍预注册回放（本细分是在 3 个分桶里事后挑出的，直接采信即 p-hacking）。

**框架自检**：baseline 本身净 −0.07R——固定规则回放（无 AI 结构止损/止盈优化）整体即贴平亏损再扣费，框架不存在系统性乐观；该偏差对基线/变体两组同等受限，边际对比结论不受影响。
