# 17 - 4h 背景趋势年龄判定

> 2026-10-10 设计定稿并实施（RULE_VERSION `v2026-10-09r2`）。替代旧「强/弱背景」口径（2026-09-24，docs/16 §N-06）。
> 实现：`backend/app/services/strategy/technical.py`（`analyze_htf_background` / `enforce_htf_constraint` / `compute_quality_score`）。

## 1. 为什么重设计

旧口径 = ADX 门控 + EMA21/55 排列 + 间距分级（≥1% 强 / <1% 弱），消费端只有两个字段（dir + grade）。两个误判洞：

| #   | 洞                                                                                                    | 后果                                         |
| --- | ----------------------------------------------------------------------------------------------------- | -------------------------------------------- |
| 1   | **熊市反弹误标多头**：EMA21>EMA55（间距≥1% 还标「强多」）但两线都在 EMA144 下方——熊内反弹结构被当趋势 | AI 在熊反弹里被鼓励做多；质量分给 +10 最高档 |
| 2   | **老化趋势仍标强**：间距是「水平量」，趋势衰竭（柱线已翻向）时距离尚未收敛，照样「强」                | 硬约束在最该放松的时刻锁得最死               |
| 3   | 间距是波动率的函数：高波币 3~5 根就 1%，低波币 40 根都不够——「强/弱」跨币语义不一致                   | 每币门槛松紧不一，硬约束不公平               |

核心替换：**主轴从「间距（空间量）」换成「交叉后根数（时间量）」**——趋势年龄就是趋势存在的时间，与币种波动率无关，一组全局常量跑全市场，参数自由度最低。

## 2. 状态空间

基础状态 5 种 × grade（仅方向性）× 注记三层：

| state    | 判据                 | dir |
| -------- | -------------------- | --- |
| 震荡     | ADX(14) < 20         | 0   |
| 均线纠缠 | EMA21/55 间距 < 0.1% | 0   |
| 多头背景 | EMA21>EMA55          | +1  |
| 空头背景 | EMA21<EMA55          | −1  |

### 2.1 趋势年龄四档（主轴）

EMA21/55 交叉事件发生后的已收盘根数 `age`：

| phase            | 判据                     | 语义                           |
| ---------------- | ------------------------ | ------------------------------ |
| 前期 launch      | age ≤ 10                 | 交叉未证明，双方向合法         |
| 中期 mid         | age ≤ 30                 | 趋势成立，结构确认             |
| 后期 late        | age > 30                 | 成熟趋势，顺势最优             |
| 衰竭期 exhausted | age > 30 ∧ MACD 柱线翻向 | 动能先于均线死亡，双向禁开新单 |

- 柱线翻向但 age ≤ 30：年龄定档 + 「动能背离」注记（不进衰竭）。
- 199 根窗口内无交叉（极老趋势）：age=None，按后期处理。
- 数值零保护：单边匀速行情柱线渐近收敛，±1e-15 浮点尾数不误判翻向。

### 2.2 宏观守卫（EMA144）

`macro_aligned = (EMA55 > EMA144) == (dir > 0)`——宏观确认的标志事件是 **EMA55 上穿/下穿 EMA144**。三线堆叠 6 种全枚举，行为收敛为二值：

| #   | 堆叠（降序） | macro_aligned | 注记                                        |
| --- | ------------ | ------------- | ------------------------------------------- |
| 1   | 21>55>144    | ✅            | 三线多头排列                                |
| 2   | 21>144>55    | ❌            | V型反转中期（EMA21已上穿144，EMA55未跟上）  |
| 3   | 144>21>55    | ❌            | 熊内反弹（144压制中·144斜率上行/走平/下行） |
| 4   | 55>21>144    | ✅            | 三线空头排列                                |
| 5   | 55>144>21    | ❌            | V型反转中期（EMA21已下穿144，EMA55未跟上）  |
| 6   | 144>55>21    | ❌            | 牛内回调（144托底中·斜率）                  |

设计原则：**144 的位置决定「能不能做」（二值行为），21 相对 144 的深浅决定「AI 怎么看」（注记语境）**。组合 2/3 行为相同（逆宏观），但 AI 语境不同（反弹已走深 vs 压制中初萌）——判定最小自由度、语境最大化。

### 2.3 动能修正器（MACD）

| momentum      | 判据                | 对 grade 的影响                       |
| ------------- | ------------------- | ------------------------------------- |
| aligned 同向  | 柱线符号与 dir 一致 | 无影响                                |
| fading 衰减   | 符号同向但连续萎缩  | 仅注记（衰减不降级，2026-10-09 拍板） |
| opposite 反向 | 符号与 dir 相反     | **衰竭判定 ∧ 强制不进「后期高分档」** |

MACD 金叉/死叉**不进 grade**（与柱线共线、事件型时效差），进注记层给「趋势年龄链」新鲜度：MACD 交叉（最早）→ EMA21 拐头 → EMA21/55 金叉死叉 → 排列成熟。

## 3. 消费端行为（grade 判定三道门）

**强档 = dist≥1% ∧ macro_aligned ∧ momentum≠opposite**（三道门全过）；任一不过降 weak / 封顶 weak。

### 3.1 硬约束锁单矩阵（`enforce_htf_constraint`，2026-10-09 r2：仅前中后开单）

| 期                      | 任何方向新单                                                    |
| ----------------------- | --------------------------------------------------------------- |
| 衰竭期（柱线已翻）      | **强制 skip**（双向禁开，矩阵最先判）+ 留痕（`htf_constraint`） |
| 中期 / 后期（宏观同侧） | 顺势放行，**逆势强制 skip** + 留痕（`htf_constraint`）          |
| 前期（交叉未证明）      | 放行                                                            |
| 逆宏观（任何期）        | 放行                                                            |

衰竭期从「放行反转打法」收紧为「双向禁开」：动能已翻向时顺势单（老趋势的尾巴）与逆势单（反转未证明）都没有正期望依据，宁可错过。原「反转合法」口径的回撤推演见 §4。

### 3.2 质量分

| 情形                     | 分值           |
| ------------------------ | -------------- |
| 同向：前期 / 中期 / 后期 | +5 / +8 / +10  |
| 同向：衰竭期             | −6             |
| 逆向：前期 / 中期 / 后期 | −6 / −10 / −12 |
| 逆向：衰竭期             | −4             |
| 逆宏观（叠加）           | −4             |

### 3.3 复盘维度「4h趋势期」（htf_phase 落库链路）

分析落库链路：`enforce_htf_constraint` stash `htf_phase`（suggest 且有 4h 数据时）→ `AIAnalysis.htf_phase`（新列 VARCHAR(12)，旧行 NULL）→ 开单时 `_ai_snapshot` 随快照自持进 `trade_records` → `build_actual_review` 新增有序维度「4h趋势期」：前期 / 中期 / 后期 / 衰竭期 / 未知（旧行与无 4h 数据兜底）。

分组验证目标：衰竭期被双向禁开后理论上不再有新样本，历史衰竭期单（若有）的劣化成绩即为该闸门的实证依据；前/中/后三档的胜率/EV 对照验证「仅前中后开单」矩阵贡献。

## 4. 行为影响推演

| 场景                         | 行为                                        | 备注                                                              |
| ---------------------------- | ------------------------------------------- | ----------------------------------------------------------------- |
| 健康单边几十根               | 停留后期，同向 +10，逆势照锁                | 后期不含反转预言，无惩罚                                          |
| V型反转（柱线翻 1 根又拉回） | 衰竭期双向禁开 → 反转单与顺势单都开不出     | r2 收紧的已知代价：假衰竭错过潜在反转单；可放宽为翻向≥3根，待实证 |
| 高波币暴力新趋势头 40h       | 前 10 根不锁逆势                            | 唯一回退点；−6−4 罚分+完整触发管线兜底                            |
| 逆宏观中期做空               | 放行但 −10−4=−14 罚分 → 68 分候选实际开不出 | 「允许但不纵容」，评分门槛自然过滤                                |
| 新上市币（4h<155根）         | 返回 None，4h 整票消失                      | 无历史 EMA144 是假信号，宁缺毋滥                                  |
| ADX≈20 抖动                  | 锁单忽开忽关                                | 固有阈值噪声，不处理                                              |

## 6. EMA144 收敛注意项

200 根窗口内 EMA144 仅 ~55 步递推，SMA 种子偏差残留 ~47%，宏观刚翻转时可能滞后错判。当前窗口已按 300 根拉取（残留 ~12%）；后续若发现宏观守卫在翻转初期钝化，优先加长拉取窗口而非改判据。
